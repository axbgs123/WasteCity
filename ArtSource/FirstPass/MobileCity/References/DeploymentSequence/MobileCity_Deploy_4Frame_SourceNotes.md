# 移动城市展开与收起四帧参考来源记录

## 范围与批准

- 关联需求：第一版美术计划 Task 6，`AN_City_Deploy` 与 `AN_City_Pack`。
- 用户于 2026-08-09 查看四帧白底 QA 后回复“继续”，批准当前展开顺序并要求继续。
- 批准序列由已批准的移动形态、两张新增中间帧和已批准的堡垒形态组成。
- 本批次只提供未来动画和机械层级设计的视觉关键帧，不包含 Blender、骨架、模型、动画曲线、根运动、FBX、Animator、Prefab 或 Unity 接入。

## 固定顺序

1. `Mobile / 0%`：支撑机构收纳，城市可移动。
2. `Deploy / 33%`：城市停止，四组支撑臂向外下落，侧平台解锁，顶面保持闭合。
3. `Deploy / 66%`：四组支撑脚落地，侧平台大部分展开，顶面锁框打开并露出建造面。
4. `Fortress / 100%`：支撑稳定，侧平台和内城建造面进入最终堡垒轮廓。

`Pack` 使用相反顺序作为视觉参考，但正式动画仍必须独立验证接触、锁定和时序，不能只在运行时粗暴倒放而忽略事件点。

## 身份与玩法边界

- 四帧保留同一前部驾驶舱、四组履带、中央装甲体、双烟囱、材质家族和默认俯视相机。
- 支撑臂、支撑脚、侧平台和顶面锁框只描述未来表现层级，不修改城市玩法根节点。
- 动画不得改变城市稳定 ID、碰撞真值、部署规则、`8×6` 逻辑网格、建筑状态或移动/堡垒判定。
- 中间帧的机械细节用于方向参考，正式制作前仍需由建模与动画人员统一 Pivot、干涉检查和收纳空间。

## 生成提示词摘要
