# UI 美术设计

## 8. UI 美术设计

### 8.1 双层 UI

**工业战术层**用于资源、生产、建造和战斗：

- 深灰半透明底板；
- 暗锈红金属边；
- 琥珀黄交互高亮；
- 紧凑、清晰、低装饰；
- 数字和状态优先。

**遗产层**用于命轨、扫描、升阶和异常：

- 大量留白与透明空间；
- 冷白细线和几何分割；
- 少量青蓝扫描；
- 高关注度时出现品红错误线；
- 不能长期取代日常 HUD。

### 8.2 常驻 HUD

- 左上：资源与人口，横向紧凑排列。
- 顶部或右上：关注度条及最近变化原因。
- 下方中央：展开、建造、研究、命轨、领袖和设置。
- 右侧：当前目标、Boss 预警和事件提示。
- 城市附近：建筑状态、缺料、受损和选中反馈。

HUD 避免大面积金属框遮挡战场。主要信息使用深灰透明面板和短边框。

### 8.3 建造界面

- 建筑卡片突出轮廓图、成本和占格。
- 卡片底部颜色只表示可建造、缺资源和锁定。
- 建造预览与甲板网格保持同一投影语言。
- 建筑分类使用生产、防御、城市、研究四类图标。
- 不使用复杂科技树式层级展示基础建筑。

### 8.4 建筑信息面板

固定信息层级：

1. 建筑名称与状态；
2. 输入、输出和库存；
3. 当前效率；
4. 停机原因；
5. 暂停、拆除和优先级操作。

缺料、输出已满、不在有效位置等原因必须使用不同图标和短文本。

### 8.5 命轨卡牌

三张卡牌共享冷白遗产框架，但具有不同核心图形：

- 袖珍宇宙：嵌套立方体与内部星点。
- 虚空债：被切走一部分的圆环和未闭合账目刻度。
- 回溯锚点：同心圆、时间刻度和逆向箭头。

卡牌不使用角色插画，重点表现“规则被改写”。

### 8.6 领袖界面

- 岑烬半身头像采用暖橙身份边框。
- 健康与受伤状态直接更换头像，不用改变整个 UI 色调。
- 主动技能图标表现炮塔被机械环包围并加速。
- 冷却使用清晰环形遮罩。

### 8.7 事件界面

- 宽幅半透明深灰面板。
- 左侧或上方为角色半身图。
- 选项采用工业按钮；遗产事件改用冷白细线按钮。
- 重要后果使用小图标提前提示，但不显示所有隐藏数值。
- 高关注度事件的边框允许出现品红错位。

### 8.8 Boss 与结算

Boss 血条使用暗紫黑底、破碎结晶边缘和清晰阶段刻度。结算页面回到稳定工业界面，在一侧加入冷白遗产扫描结果。

### 8.9 图标规范

- 统一 45° 或正视扁平图形，不混用复杂透视。
- 轮廓粗细统一。
- 资源图标以实体轮廓为主。
- 状态图标以几何符号为主。
- 图标底色透明，功能颜色不超过两种。
- 16–24 像素显示时仍能辨识。

建议首版图标：

- 4 个资源；
- 9 个建筑；
- 7 个建筑状态；
- 5 个科技；
- 3 个命轨；
- 2 个领袖技能；
- 8 个通用操作；
- 6 个危险与目标提示。
