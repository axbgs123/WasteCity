# 《废土移动城市》Demo 资源生成方式目录

> 本目录按照“怎么生成”对资源分类。资产实体仍保存在对应功能目录中，避免重复文件。

## 1. 生成方式总览

| 代码 | 生成方式 | 主要用途 | 当前阶段交付 |
|---|---|---|---|
| T2I | AI 文生图 | 第一轮风格探索和独立概念 | PNG＋提示词 |
| REF | AI 参考图一致性生成 | 同系列建筑、敌人、角色状态 | PNG＋参考图＋提示词 |
| IMG2IMG | AI 图生图细化 | 保留构图并统一材质、视角 | PNG＋源图＋提示词 |
| SHEET | AI 设计板生成 | 阵列、状态、比例和结构对比 | PNG 设计板 |
| MANUAL | 人工绘制或修图 | 透视修正、拆分、清理和统一 | PSD/KRA＋PNG |
| VECTOR | 矢量绘制 | UI 图标、网格、状态符号 | SVG＋PNG 预览 |
| PROC | Unity 程序化制作 | 扫描、网格、预警、选中效果 | 设计图＋实现说明 |
| PARTICLE | Unity 粒子与 Shader | 烟尘、火花、命中、异常 | 效果板＋实现说明 |
| DOC | 文档与表格 | 规范、提示词、授权和清单 | MD/PDF/CSV |

## 2. AI 文生图（T2I）

适合尚无既有视觉参考、需要探索整体方向的内容：

- 移动城市第一轮轮廓；
- 锈蚀平原第一轮环境；
- 安全矿区与结晶裂谷第一轮方向；
- 岑烬第一轮角色探索；
- 晶壳母体第一轮形态探索；
- 四幕事件氛围缩略图；
- 升阶结尾关键帧草案。

每项第一轮生成 4–8 张构图草案。必须使用统一风格前缀、65°俯视、左上主光和统一负面提示词。

## 3. AI 参考图一致性生成（REF）

正式概念阶段最重要的生成方式。先选择风格基准图，再扩展同系列资产。

| 资产系列 | 必须使用的主参考图 |
|---|---|
| 城市 | 选定的移动城市收起状态 |
| 建筑 | 选定的九类建筑家族阵列 |
| 普通敌人 | 选定的三种敌人比例阵列 |
| Boss | 选定的晶壳母体第一阶段 |
| 岑烬 | 选定的健康状态半身立绘 |
| 环境 | 选定的锈蚀平原基准图 |
| 工业 UI | 选定的工业战术 HUD |
| 遗产 UI | 选定的命轨三选一界面 |

一致性要求：

- 不改变摄像机角度和主光方向；
- 不改变材质细节等级；
- 不重新设计已有核心结构；
- 状态图只改变损伤、灯光、姿态或局部部件；
- 建筑系列保留统一底座、色板与接口。

## 4. AI 图生图细化（IMG2IMG）

适用于已经确定构图，但需要改善结构、材质或系列一致性的图片：

- 城市结构细化；
- 建筑轮廓修正；
- Boss 三阶段一致性修正；
- 岑烬健康与受伤状态统一；
- 环境材质统一；
- UI 色彩和边框统一。

不用于生成可读中文、精确 UI 图标、最终透明游戏资产或严格机械结构图。

必须保留原始输入图、参考图、提示词、重绘参数和最终选定版本。

## 5. AI 设计板（SHEET）

用于比较、比例和状态统一：

- 城市收起与展开对比；
- 空甲板普通与建造状态；
- 九类建筑家族阵列；
- 建筑状态板；
- 三种普通敌人比例阵列；
- 晶壳母体三阶段；
- 敌人受击和死亡反馈；
- 四幕事件氛围板；
- 安全矿区和结晶裂谷对比；
- 四种资源视觉板；
- 关注度四阶段；
- 三条命轨；
- Boss 预警；
- 升阶关键帧。

设计板不能替代单项图片。设计板确定后，每项仍要单独生成 PNG。

## 6. 人工绘制与修图（MANUAL）

必须人工检查：

- 城市履带数量和连接结构；
- 甲板透视与格子尺寸；
- 建筑底座和接口统一；
- Boss 三阶段主体一致；
- 岑烬两个状态的人物一致；
- 透明背景边缘；
- 阴影方向；
- AI 伪文字、水印和异常结构。

必须分层的内容：

- 城市主体、核心、甲板、履带和扩展平台；
- 建筑底座、主体、活动部件、发光和损伤；
- 角色主体、背景和状态覆盖；
- UI 面板、边框、图标和异常覆盖；
- 特效主体、发光、烟雾和碎片。

推荐源文件为 PSD 或 KRA，清理预览使用 PNG。

## 7. 矢量绘制（VECTOR）

UI 图标和规则性图形不使用 AI 生图成品，建议 AI 出黑白草案后再重绘为矢量。

### 资源

- 4 个资源图标；
- 9 个建筑图标；
- 7 个建筑状态图标；
- 5 个科技图标；
- 3 个命轨符号；
- 2 个领袖技能图标；
- 8 个通用操作图标；
- 6 个危险与目标图标；
- 建造网格和格子状态；
- Boss 阶段刻度；
- 关注度阶段符号。

主交付为 SVG，同时导出 256×256 PNG 预览，并检查 16、24、32 和 64 像素可读性。

## 8. Unity 程序化图形（PROC）

以下内容只制作效果示意图，不制作固定静态成品：

- 甲板建造网格；
- 可用、选中和不可用格；
- 建筑放置预览；
- 关注度扫描框；
- Boss 范围预警；
- 掘地路径；
- 研究站扫描环；
- 回溯残影；
- 目标方向提示；
- 建筑选中轮廓；
- 战争迷雾边缘。

当前阶段交付 PNG 效果图，以及色值、透明度、动画方向和持续时间说明。

## 13. 执行顺序

### 第一批：风格基准

1. 移动城市收起状态；
2. 空甲板；
3. 九类建筑家族阵列；
4. 三种普通敌人阵列；
5. 锈蚀平原；
6. 工业战术 HUD；
7. 岑烬健康状态。

### 第二批：一致性扩展

1. 城市展开和状态变化；
2. 每种建筑单体；
3. 每种敌人单体；
4. 岑烬受伤状态；
5. 其他环境；
6. UI 子页面。

### 第三批：特效与异常

1. 关注度四阶段；
2. 三条命轨；
3. Boss 三阶段和预警；
4. 升阶结尾；
5. 战斗与生产效果。

第一批风格基准确认后，才能开始第二批批量生成。
