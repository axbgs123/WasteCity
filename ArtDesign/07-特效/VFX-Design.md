# 战斗与系统特效美术设计

## 7. 战斗与系统特效

### 7.1 特效总原则

- 操作反馈优先于装饰。
- 特效持续时间短，中心信息明确。
- 玩家工业特效偏暖黄和橙色。
- 遗产特效偏冷白与少量青蓝。
- 未知异常偏品红和紫黑。
- 红色只用于即时危险与损伤。
- 同屏大量敌人时减少透明烟雾面积。

### 7.2 城市移动与碾压

- 履带扬起低矮灰褐尘土。
- 地面留下宽阔履带压痕。
- 撞击瞬间出现短促暖白冲击闪光。
- 小型敌人产生明确击退、结晶碎片和暗色生物液体。
- 尸体回收时出现污绿粒子被吸向城市底部回收口。
- 避免夸张红色血浆。

### 7.3 炮塔射击

- 枪口火光为短促暖黄锥形。
- 弹道使用细小暖白曳光，不绘制粗激光。
- 命中无甲目标：暗色液体＋小碎片。
- 命中重甲：浅白火星＋暗紫结晶碎屑。
- 缺弹：弹药舱红灯和短促 UI 提示，不播放假开火。

### 7.4 生产特效

- 采矿：局部粉尘、矿石碎片、钻头火星。
- 冶炼：暗橙炉光、短烟、热空气扭曲。
- 装配：机械臂火花、工位指示灯、密封出料动作。
- 堵塞：接口红橙闪烁、物料停止在可见位置。
- 维修：暖黄焊接弧光和少量火花。

### 7.5 关注度

| 阶段 | 画面表现 |
|---|---|
| 未锁定 | 无异常覆盖 |
| 异常回波 | 远处短促冷白扫描，城市核心出现青蓝细线 |
| 定向观测 | 局部品红噪点、敌袭方向扫描框 |
| 坐标锁定 | 紫黑错误阴影、重复边缘、明确指向城市的扫描束 |

异常不得持续覆盖 UI 和战场，强烈效果只在阈值触发及 Boss 演出时出现。

### 7.6 三条命轨

**袖珍宇宙**：

- 冷白小型几何空间包裹强化建筑。
- 内部尺度似乎比外部更大。
- 坍缩时向内收缩，不向外爆炸。

**虚空债**：

- 建造轮廓先完成，随后出现紫黑缺口。
- 欠债建筑底座存在细小品红裂纹。
- 还债时裂纹逐段闭合。

**回溯锚点**：

- 锚点是冷白同心环与垂直刻度线。
- 回溯时物体留下多层透明残影并逆向归位。
- 关注度保留以品红细线穿过回溯画面表现。

### 7.7 Boss 预警

- 范围冲击：地面同心圆由暗红转为明亮红橙。
- 召唤：孵化裂隙周围出现暗紫脉冲。
- 掘地：地面隆起和方向性碎晶路径。
- 阶段转换：画面短暂降低饱和度，Boss 品红轮廓错位。
- 所有预警同时依靠形状、颜色和动画，不只依赖颜色。

### 7.8 升阶与结尾

1. 工业设施的暖黄灯光依次熄暗。
2. 城市核心冷白光缝扩大。
3. 青蓝几何结构从甲板向外构成短暂星图。
4. 垂直信号升向天空。
5. 场景短暂明亮，表现文明突破。
6. 信号远端出现不属于城市的品红响应。
7. 巨大模糊扫描结构掠过天空，留下结尾悬念。
