# IDEA-0023 F6 透明贴图批次

## 批次用途

本批次用二十张正式透明图替换文明扩展中最明显的程序化占位：四类军队单位、林溪、韩骨、次城、前哨、运输队、军队/世界/政务三个页签，以及守卫、跟随、远征、撤退、运输、通信、忠诚、救援八个运行时状态徽记。已有权威世界坐标的对象当前使用面向镜头的贴图/公告板，角色使用政务面板头像；均不代表模型、动画或特效已经完成。

## 制作与许可记录

- 生成工具：OpenAI `image_gen`（GPT Image），2026-08-28；每项资产独立生成。
- 提示词版本：`idea0023-v1`；逐项摘要与世界观简介见同目录 manifest。
- 背景处理：生成时使用纯 `#00ff00` 或 `#ff00ff` 色键；随后使用 Codex imagegen skill 的 `remove_chroma_key.py`，参数为 `--auto-key border --soft-matte --transparent-threshold 12 --opaque-threshold 220 --despill`。
- 后期处理：只做透明边缘处理、保持宽高比缩放、主体居中和安全区归一化；未拼接第三方素材，未绘制文字、数字、状态或背景。
- 许可/来源：由本项目通过 OpenAI 图像生成工具新生成，按项目对生成内容可使用的条款用于 WasteCity；未下载或复制 GitHub 项目美术。
- 参考边界：只借鉴 Widelands/OpenRA/Wesnoth 的小尺寸可读性、表现与状态分离、图片与运行时偏移分离原则，不复制其资产或布局。
