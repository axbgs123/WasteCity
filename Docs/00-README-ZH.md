## 3. 已确定的产品信息

```text
项目名称：《废土移动城市》
目标平台：Windows PC
引擎：Unity 2022.3.62f1（修订号 4af31df58517）
画面：2D 俯视角，URP 2D Renderer
操作：键盘与鼠标
首版用途：游戏产品经理秋招作品集、公开试玩、正式版开发起点
开发方式：个人主导设计，AI 辅助生产
开发周期：14 天，每天约 10 小时
首次体验：30-40 分钟
熟练玩家：20-25 分钟
```

核心体验：

```text
移动探索
→ 选择展开位置
→ 建立生产与防御
→ 发展提高关注度
→ 应对定向攻击
→ 坚守或收起撤离
→ 击败 Boss 并完成文明升阶
```

## 6. 技术关键规则

### 内容扩展

- 内容使用唯一 `ContentCatalog`；
- 资源、建筑、敌人、科技、命轨、角色和事件使用数据驱动；
- 不允许不同 AI 分别创建第二套库存、事件总线、时钟、存档或本地化系统。

### 稳定 ID

使用至少三段的小写命名空间：

```text
core.resource.iron
core.building.machine_gun_tower
core.enemy.devourer
core.fate.pocket_universe
```

发布后的 ID 不随显示名称和翻译修改。

### 本地化

- 玩家可见文字使用 `TextKey`；
- 首版只制作简体中文表；
- 不在规则代码中直接写最终显示文本。

### 存档

- 包含 `gameVersion`、`saveSchemaVersion` 和内容来源；
- 写入使用临时文件→校验→替换；
- 迁移前自动备份；
- 旧 ID 通过迁移映射处理；
- 未知内容不能导致整个存档崩溃。

### Mod

首版目标是 `Mod-ready`，不是 `Mod-supported`。首版只做好 ID、内容注册、本地化和存档基础，不扫描外部 Mods 目录。

## 7. 新电脑环境准备

1. 安装 Unity Hub；
2. 安装项目固定版本 Unity `2022.3.62f1`（含 Windows Build Support）；
3. 安装 Windows Build Support；
4. 安装 Git 和 Git LFS；
5. 将本交接包放到不受聊天软件清理影响的普通项目目录；
6. 创建 Unity 工程后立刻初始化 Git；
7. 在真实 Windows 设备进行候选发布版测试。

项目创建后，将准确的 Unity 补丁版本记录到：

```text
ProjectSettings/ProjectVersion.txt
```
