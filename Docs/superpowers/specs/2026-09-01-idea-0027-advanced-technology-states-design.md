# IDEA-0027 高级科技状态与四路线差异设计

## 目标与范围

本阶段把 `IDEA-0026` 的无状态科技修正扩展为可保存的跨帧状态，并完成 44 个科技节点的自然研究闭环。保持 44 个稳定科技 ID、49 条前置边、6 个桥节点、现有成本/时长、`64×48` 地图、seed `8128`、资源/建筑 ID 和科技树布局；不新增模型、动画、音频、资源或科技节点。

原 15 个 `PreviewOnly` 节点改为 `Researchable`。`core.research.alloy-armor` 与 `core.research.sword-riding` 继续由 `CivilizationResearchAvailability` 保持文明 Lv.2 门槛，不能因目录状态变化在 Lv.1 提前开放。

## 参考与取舍

- Mindustry 将状态内容和科技目标作为规则对象，不由界面文案决定行为。
- Unciv 的 uniques 把效果与条件组合，完成科技只授予能力，不复制消费者规则。
- Freeciv 以稳定效果类型、范围和需求组合多个修正。

WasteCity 只采用所有权原则，不复制第三方代码、美术、名称、数值或布局，也不引入依赖。优先复用仓库内既有 `TechnologyOverloadModel`、`SwordIntentModel`、`InfectionModel`、`PsionicResonanceModel`、`MindControlModel`、`ShieldPulseModel`、`HealthModel` 与 F3 军队模型。

## 所有权

`ResearchCatalog` 继续拥有科技身份、成本、时长、前置和发布状态。`ResearchEffectCatalog` 继续拥有“完成科技解锁何种机制及参数”，但不保存实时层数、计时或护盾。

实时状态由目标领域持有：

- 塔：过载阶段、冷却与自动维修周期；
- 敌人：剑意、感染、共鸣和精神操控；
- 建筑/核心：护盾、自动维修和再生周期；
- 军队：最大生命修正、再生与傀儡容量；
- 角色：基因剪接临时特质；
- 研究：集体意识的新研究继承。

UI 和管理台只通过窄 facade 消费不可变投影，不直接修改集合。统一 `ResearchStatusCatalog` 只登记稳定状态 ID、名称、来源科技、允许目标、持续/周期、叠加和存档边界。

## 正式规则

### 科技路线

- 弹道学：弹药炮塔射程 `+20%`、弹药伤害 `+15%`。
- 无人系统：自动维修站半径 `6` 格、基础每 `6` 秒恢复 `20` 耐久；科技效率 `-15%` 后周期为 `5.1` 秒。无人机本阶段只用维修站/状态徽记表达，不生成新 3D 单位。
- 能量武器：解锁激光塔；选中任一己方激光塔可主动过载。过载强化 `5` 秒，攻速 `×2` 且能量伤害 `+30%`；随后停火 `3` 秒；从激活起总冷却 `30` 秒。全局暂停冻结全部阶段。

### 修仙路线

- 符箓入门：所有己方城墙物理承伤变为 `80%`。
- 剑阵初解：保留剑阵伤害 `+15%`；剑阵塔/御剑台实际命中每个目标最多每秒叠 1 层剑意，上限 `20`。满层造成 `20×5%` 目标最大生命的真实伤害并清零。
- 傀儡术：单傀儡工坊容量 `3→4`；制造仍为 `20` 秒、`1` 合金 + `1` 灵铁，维护仍为每单位 `60` 秒消耗 `1` 能晶，断供休眠。

### 血肉路线

- 孢子散布：孢子塔生物伤害 `+15%`；实际生物命中每个来源最多每秒加 1 层感染。感染每秒造成目标最大生命 `2%` 伤害，不自然衰减；达到 10 层后源目标清零，并按稳定敌人 ID 向半径 `3` 格内其他敌人施加 5 层。死亡或成功精神操控清除。
- 巨兽培育：培育巨兽最大生命 `+10%`，当前生命按相同健康比例调整，不能借研究完成重复治疗。
- 酸液喷吐：酸液塔对重甲最终伤害 `+30%`。
- 组织再生：保持建筑每秒 `1` 点，并补齐活动军队单位每秒 `1` 点；暂停冻结。
- 基因剪接：首次正式完成时给当前领袖 `300` 秒最大生命 `+20%` 特质。保持当前健康比例；到期恢复基础上限。自然完成和 Development 精确完成共用幂等键，旧 schema 迁移不补发。

### 灵能路线

- 心灵尖塔：灵能伤害继续使用 `DamageMatrix`；命中标记目标 `5` 秒，最多同时 10 个目标。任一标记目标受到心灵尖塔的灵能伤害时，其余标记目标同步承担实际主伤害的 `30%`，同步伤害不能递归触发。
- 心灵护盾：每座在线护盾发生器每 `8` 秒为半径 `6` 格内己方已完成建筑和城市核心补充 `20` 护盾，单目标上限 `100`；护盾先于生命承伤。该数值覆盖旧展示文字中的 `25`。
- 精神操控：心灵尖塔命中普通非重型目标时，以稳定命中序号和目标 ID 产生 `0–99` 确定性值，低于 `10` 时成功；精英、Boss 和重型免疫。成功目标退出敌军并转换为本次战役友方受控单位，保留当前生命；死亡计入受控单位损失。若现役战役没有单位空间，则清除敌对状态但不生成额外实体，HUD 明确显示“已控制”。
- 集体意识：开始新研究时继承基础时长 `20%` 的进度，即剩余时间从 `80%` 开始；只在开始事务时应用一次，取消退款规则不变。既有同星球免费远程控制继续生效。
- 预知和 EMP：继续复用已生效的 `+50%` 预警与机械目标当帧抑制，不创建同义状态。

## schema 35

在 `FormalThreeDSaveData` 新增非空 `researchEffectState` 聚合：

- 配置签名 `builtin:research-effect-state@1`；
- revision 与下一实例高水位；
- 活动状态数组：稳定实例 ID、创建序号、effect/status ID、目标类型/稳定 ID、阶段、剩余规则时间、层数、周期余量和当前值；
- 已提交一次性效果键数组。

数组按创建序号和稳定 ID 规范排序。同一状态/目标服从目录定义的 Singleton、Refresh、StackAndRefresh 或 Recharge 策略。计时只使用规则时间；周期余量必须小于周期。

`34→35` 必须先以 schema 34 原始结构验证 payload hash，再创建空状态聚合与空奖励账本。不得从 completed research、建筑、角色或敌人历史推断临时状态，也不得补发基因特质。schema `31→32→33→34→35` 单向迁移，schema `1–30` 继续属于 legacy 2D，未来 schema 拒绝。

未知状态、悬空目标、重复 ID、无效高水位、非法目标类型/阶段/时间/层数/周期余量/当前值、同组重复单例或重复奖励键均拒绝加载。
