# 修仙剑意、御剑台与傀儡维护闭环设计

## 目标

完成正式路线图 F1 的修仙路线里程碑：

- 飞剑命中叠加剑意，满层触发真实斩杀；
- “御剑术”把剑阵台原地升级为御剑台；
- 傀儡需要稳定的灵力维护，断供后休眠并可恢复；
- 敌人剑意和傀儡维护状态可保存、可兼容旧存档；
- 所有新增表现继续使用程序化占位符和稳定 `VisualSlot` ID。

## 文档明确规则

主 GDD 已明确：

- 飞剑命中叠加剑意；
- 剑意上限 `20` 层；
- 满层触发“层数 × 5% 最大生命值”的真实伤害；
- 斩杀后剑意清零；
- “御剑术”解锁御剑台升级，并使飞剑射程 `+30%`；
- 傀儡是由灵石驱动的自动作战单位。

项目当前使用连续 DPS 模拟塔攻击，没有离散飞剑弹丸；项目资源表也没有独立“灵石”。以下规则是为了接入现有系统所需的最小推断。

## 剑意规则

### 叠层

- 剑阵台和御剑台造成实际真元伤害后，对目标附加 `1` 层剑意。
- 同一个塔是一个独立命中来源；连续 DPS 最多每 `1` 秒附加 `1` 层，首次实际伤害立即附加。
- 没有造成实际伤害时不叠层。
- 多座塔可以分别叠层。
- 剑意只作用于存活、未被精神控制的敌人。
- 剑意不自然衰减；死亡、精神控制或斩杀后清除。

### 满层斩杀

- 添加一层后达到 `20` 层时立即触发。
- 伤害为触发时层数 `20 × 5% = 100%` 目标最大生命值。
- 真实伤害忽略护甲、物理减伤、伤害矩阵和护盾，保证“斩杀”语义成立。
- 真实伤害仍触发生命模型的受伤与死亡事件。
- 斩杀结算后剑意清零。
- 已死亡目标不会重复触发斩杀。

### 运行时状态

新增纯 C# `SwordIntentModel` 管理层数和斩杀计算，新增 `SwordIntentEmitterModel` 管理连续 DPS 的一秒命中节奏。

新增 `EnemySwordIntentStatus`：

- 挂接在 `PlaceholderEnemy`；
- 显示当前层数；
- 触发时调用 `HealthModel.ApplyTrueDamage`；
- 占位反馈稳定 ID 为 `cultivation.status.sword-intent`；
- 精神控制成功时清除状态和占位反馈。

## 御剑台升级

新增升级目标：

- ID：`cultivation.building.sword-riding-platform`；
- 名称：`御剑台`；
- 来源：已完成的 `cultivation.building.sword-array-tower`；
- 前置研究：`core.research.sword-riding`；
- 前置文明等级：`2`；
- 升级成本：`20` 灵铁；
- 占格：`1×1`；
- 建造时间：`12` 秒；
- 最大生命：`300`。

成本和耐久沿用当前重型机枪塔升级的量级，但使用修仙路线材料。御剑台沿用剑阵台的真元 DPS、飞剑消耗与基础射程；“御剑术”对剑阵台和御剑台都提供文档明确的 `1.3×` 射程。此次不额外增加伤害、射速或飞剑节省倍率。

御剑台加入 `BuildingCatalog.All` 和 `DefenseTowerCatalog`，但不加入直接建造菜单，只能通过原地升级获得。建筑本身的稳定 ID 同时作为正式美术替换槽。

## 傀儡维护

### 资源代理

项目没有独立灵石资源，当前修仙研究和生产链使用能晶作为基础灵力资源。因此本里程碑使用 `ResourceIds.EnergyCrystal` 作为灵石代理，不新增资源类型。

### 维护规则

- 新傀儡生成时自带 `60` 秒灵力。
- 每个傀儡每 `60` 秒消耗 `1` 能晶。
- 有资源时扣除并开始下一个 `60` 秒周期。
- 资源不足时维护进度停在到期点，傀儡进入休眠。
- 休眠傀儡停止移动和攻击，但不会死亡、掉血或计入损失。
- 能晶恢复后自动扣除 `1` 并立即恢复行动。
- 通过不带库存引用的测试或兼容调用创建的傀儡不启用维护，保持现有测试隔离。

新增纯 C# `PuppetMaintenanceModel` 管理计时、扣费和休眠。`PlaceholderPuppet` 负责：

- 持续更新维护模型；
- 开关 `FriendlyUnitAgent`；
- 在激活时使用 `cultivation.unit.puppet`；
- 在休眠时使用 `cultivation.unit.puppet.dormant`。

## 存档

存档升级为 schema `27`。

### 敌人

`EnemySnapshot` 新增：

- `swordIntentStacks`。

schema `27` 恢复敌人剑意；schema `26` 及更旧默认 `0`。受控敌人即使快照异常包含剑意，也恢复为 `0`。

### 傀儡

`FriendlyUnitSnapshot` 新增：

- `maintenanceElapsed`；
- `maintenanceActive`。

schema `27` 恢复傀儡维护计时与激活状态；schema `26` 及更旧傀儡获得新的完整 `60` 秒周期并保持激活。巨兽继续复用该快照类型，但忽略这两个字段。

## 测试与验收

1. EditMode 测试覆盖剑意上限、满层斩杀、清零、恢复、无效输入和命中节奏。
2. EditMode 测试覆盖真实伤害忽略护甲与护盾但仍触发死亡事件。
3. EditMode 测试覆盖御剑台升级前置、成本、目录和射程规则。
4. EditMode 测试覆盖傀儡维护扣费、休眠、恢复、负时间和状态恢复。
5. PlayMode 测试证明剑阵台与御剑台实际命中会叠层并显示稳定状态槽，非飞剑塔不会叠层。
6. PlayMode 测试证明满层剑意能斩杀带护盾目标，精神控制会清除剑意。
7. PlayMode 测试证明傀儡断供休眠、补给恢复，并切换稳定表现 ID。
8. 存档测试证明 schema `27` 往返剑意与傀儡维护，schema `26` 使用安全默认值。
9. 运行全部 EditMode、PlayMode、无界面编译和 Windows 64 位构建。
10. 真实 Windows 10/11 独立程序冒烟继续标记待补；通过前不作为候选发布版。

## 非目标

- 不制作离散飞剑弹丸、飞剑环绕动画或正式特效。
- 不增加灵石资源、灵脉采集或新的生产配方。
- 不让傀儡维护失败造成死亡或永久损失。
- 不实现高周波飞剑桥节点。
- 不增加御剑台额外伤害、射速、弹药节省或多目标攻击。
- 不导入正式美术、模型、动画或音频。
