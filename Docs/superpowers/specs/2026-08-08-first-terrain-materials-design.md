# 《废土移动城市》第一版场景地表材质设计规格

> 日期：2026-08-08<br>
> 关联需求：`IDEA-0004`<br>
> 需求状态：已明确 / 已批准 / 开发中<br>
> 父规格：`Docs/superpowers/specs/2026-08-08-first-art-pass-production-design.md`<br>
> 当前阶段：材质设计与源资源前期；Task 13 通过前不得接入 Unity 正式场景

## 1. 目标

为默认倾斜正交俯视视角建立第一版统一地表语言。玩家应先读出地形类别、通行危险与资源气氛，再看到局部纹理细节。首批地表采用“风格化 PBR、暖黄干旱废土、贴图优先、少量几何增强”，不使用纯色块，也不依赖高密度写实扫描资产。

本规格覆盖七类地表：

1. 普通荒地 `Wasteland`；
2. 岩石地 `Rocky`；
3. 湿地 `Wetland`；
4. 结晶地表 `Crystal`；
5. 大型废墟 `Ruins`；
6. 深水 `DeepWater`；
7. 悬崖 `Cliff`。

其中 `Crystal` 是地表类型；可采集能晶仍是独立资源节点模型，两者不得合并为同一资产或同一玩法真值。

## 2. 与当前玩法的边界

- 地形通行、阻挡、移动倍率、资源节点、建筑合法性和存档继续由现有规则与稳定 ID 决定；
- 材质、混合遮罩、模型、贴花、浅水面和碎石只负责表现，不得反向决定玩法；
- 不以 Mesh Collider、材质颜色或 Height 贴图替代 `WorldTraversalKind`、`TerrainKind` 或资源节点数据；
- 地表表现必须能在关闭正式资源映射后回退到现有灰盒；
- Task 13 通过前只允许完成规格、参考板、无缝贴图原型和源文件前期，不修改正式场景、Shader、材质、Prefab 或 Build Settings；
- Task 13 通过后才允许按独立实施计划导入 Unity、制作主材质、配置混合和进行 Windows 构建验收。

## 3. 视觉方向

### 3.1 总体风格

- 风格化 PBR，不追求照片级写实；
- 俯视距离下保留大形状、低频明暗和清楚材质差异；
- 基础气候为暖黄、干燥、尘土覆盖的工业废土；
- 废土底色统一，湿地、结晶、深水等局部材质在同一世界中自然生长或侵蚀；
- 不烘焙固定方向阴影、高光或太阳光，避免旋转和混合后穿帮；
- 每张贴图保留约 70% 中低频信息，微观噪声只作为近看补充。

### 3.2 共同色彩锚点

所有地表至少共享一种暖黄尘土成分，主要色锚为：

| 用途 | sRGB Hex | 说明 |
|---|---|---|
| 压实荒土 | `#66513A` | 全地图基础暗土 |
| 风化黄土 | `#887054` | 主要暖色表面 |
| 深色碎屑 | `#3D342B` | 石缝、碎石、污染 |
| 锈橙沉积 | `#8A4D28` | 工业废土强调色 |

独立地表的冷色、湿色和发光色只能作为局部偏移，不能完全丢失上述共同尘土语言。

## 4. 通用贴图交付

### 4.1 每类地表的固定文件

每类地表交付一套 `2048×2048` 无缝纹理：

```text
T_Terrain_<Type>_BaseColor.png
T_Terrain_<Type>_Normal.png
T_Terrain_<Type>_Mask.png
T_Terrain_<Type>_Height.png
```

- `<Type>` 固定为 `Wasteland`、`Rocky`、`Wetland`、`Crystal`、`Ruins`、`DeepWater`、`Cliff`；
- BaseColor：8-bit RGB/RGBA PNG，sRGB；无固定方向光照和环境阴影；
- Normal：8-bit RGB PNG，Tangent Space，Linear；方向按 Unity 法线导入设置验收；
- Mask：8-bit RGBA PNG，Linear；R Metallic、G Ambient Occlusion、B Detail Mask、A Smoothness；
- Height：16-bit 灰度 PNG，Linear；黑低白高，必须可平铺，不直接作为玩法高度；
- 一张 `2048×2048` 纹理覆盖外城约 `4×4` 个逻辑格，即约 `512 px/格`；
- 四边必须像素级可平铺，旋转 `0°/90°/180°/270°` 后不得出现明显方向接缝；
- 贴图源文件必须保留可编辑分层文件，使用 `.kra`、`.psd`、`.sbs` 或等价无损源文件。

### 4.2 共享辅助贴图

```text
T_Terrain_MacroVariation_01.png   1024×1024 灰度 Linear
T_Terrain_DustOverlay_01.png      1024×1024 灰度 Linear
T_Terrain_WetnessOverlay_01.png   1024×1024 灰度 Linear
```

- MacroVariation 覆盖约 `16×16` 个外城格，只提供约 `±5%` 的亮度或色相变化；
- DustOverlay 用于不同干地之间的共同积尘，不能改变玩法边界；
- WetnessOverlay 用于湿地与岸线邻接，不能把普通荒地误读为深水；
- 三张辅助图也必须无缝，不包含固定世界坐标图案。

## 5. 七类地表内容

### 5.1 普通荒地 `Wasteland`

这是全地图的视觉母材质，其他地表都应能通过尘土或风化自然接回它。

| 成分 | 面积占比 |
|---|---:|
| 压实赭黄土 | 65% |
| 浮尘与风积层 | 18% |
| 小砾石 | 10% |
| 浅裂纹 | 4% |
| 车辙、锈色污染或旧工业痕迹 | 3% |

颜色以 `#66513A`、`#887054`、`#3D342B`、`#8A4D28` 为主；Smoothness 主要落在 `0.12–0.25`，Metallic 接近 `0`。裂纹必须稀疏、浅且不形成规则网格；车辙只做非常弱的方向暗示，避免整张地图出现重复道路。

### 5.2 岩石地 `Rocky`

| 成分 | 面积占比 |
|---|---:|
| 扁平岩板 | 45% |
| 暖黄积尘 | 25% |
| 砾石区 | 20% |
| 岩缝 | 7% |
| 风化或矿物痕迹 | 3% |

主色 `#5B5042`、`#71604A`、`#302B26`；Smoothness `0.18–0.34`。岩板以宽、钝、低起伏为主，不能像尖锐悬崖。贴图负责主体，另准备 4–6 个低模散石增强轮廓；散石不承担阻挡真值。

### 5.3 湿地 `Wetland`

| 成分 | 面积占比 |
|---|---:|
| 深色湿泥 | 45% |
| 浅污水洼 | 20% |
| 干土小岛 | 15% |
| 黑色矿物污泥 | 10% |
| 根系或枯草痕迹 | 5% |
| 向荒地过渡的泥土 | 5% |

主色 `#3C3829`、`#454934`、`#28302D`、`#69533A`；湿泥 Smoothness `0.45–0.62`，浅水区域 `0.70–0.86`。贴图表达泥地，单独的低面数浅水层只负责反光与轻微流动；水层不得扩大可见玩法范围。

### 5.4 结晶地表 `Crystal`

| 成分 | 面积占比 |
|---|---:|
| 暖黄荒土 | 65% |
| 深色玻化地表 | 18% |
| 灰青晶壳 | 10% |
| 细晶脉 | 4% |
| 灼烧或玻化边缘 | 3% |

主色 `#61503A`、`#263234`、`#526563`、`#4D8F92`；玻化区域 Smoothness `0.55–0.78`。允许非常弱的青色自发光，目标强度 `0.10–0.25`，默认镜头下只用于辨识，不能把整块地面变成霓虹灯。

地表晶脉是气候和地质表现；可采集能晶节点必须使用独立模型、独立稳定 ID 和独立高亮，不得烘焙进该贴图。

### 5.5 大型废墟 `Ruins`

| 成分 | 面积占比 |
|---|---:|
| 风化混凝土 | 35% |
| 破损沥青或工业地坪 | 20% |
| 暖黄积尘 | 20% |
| 碎石和瓦砾 | 15% |
| 标线、排水或旧结构痕迹 | 7% |
| 裸露金属 | 3% |

主色 `#55514A`、`#393936`、`#756047`、`#8A682E`。贴图提供废弃工业地表，另做 6–8 个低模模块：破裂地坪、两种瓦砾堆、钢筋混凝土块、断管、排水沟、边缘板和可选旧标线件。模块只用于打破平面和轮廓，不改变 Ruins 的规则范围。

### 5.6 深水 `DeepWater`

| 成分 | 面积占比 |
|---|---:|
| 蓝黑不透明水体 | 75% |
| 宽而缓慢的涟漪 | 15% |
| 油膜污染 | 7% |
| 锈橙污染沉积 | 3% |

主色 `#101F29`、`#09131B`、`#26343A`、`#6A4427`；Smoothness `0.78–0.94`。深水应显得危险、浑浊且不可见底，不采用热带透明蓝水。贴图与简单共享水面网格共同表现；岸线由独立窄过渡带衔接，但不可用柔化效果模糊“不可通行”的识别。

### 5.7 悬崖 `Cliff`

| 成分 | 面积占比 |
|---|---:|
| 大块风化岩层 | 55% |
| 深裂缝 | 20% |
| 暖黄积尘 | 15% |
| 坡脚碎石 | 7% |
| 矿物竖痕 | 3% |

主色 `#4C3B2D`、`#292521`、`#796047`。悬崖必须用贴图加最小模块几何表达明确高度差，至少包含直段 A、直段 B、内角、外角、端头和顶部封口 6 个模块。坡脚碎石负责隐藏几何接缝，但不得让玩家误判为可通行坡道。

## 6. 无缝衔接方案

### 6.1 软混合组

`Wasteland`、`Rocky`、`Wetland`、`Crystal` 使用同一地形主材质和控制遮罩进行柔和混合：

- 每个局部区域最多同时采样两个主要地表；
- 第三个视觉层只允许使用共享 Dust 或 Wetness Overlay；
- 混合权重来自后续批准的控制图或顶点权重，不来自玩法逻辑反推；
- 相邻贴图保持相近的共同尘土亮度和宏观尺度，避免混合中出现明显明度断层；
- Normal、Height、AO 和 Smoothness 必须与 BaseColor 使用同一混合权重；
- 不使用只混 BaseColor、但法线和光滑度仍硬切的伪过渡。

推荐世界过渡宽度：

| 相邻地表 | 过渡宽度 |
|---|---:|
| Wasteland ↔ Rocky | 1.0–1.5 外城格 |
| Wasteland ↔ Wetland | 0.8–1.5 外城格 |
| Wasteland ↔ Crystal | 0.8–1.2 外城格 |

### 6.2 清晰规则边界组

`DeepWater`、`Cliff`、`Ruins` 仍需保持明确玩法边界，但视觉接缝不能像两块方形贴纸：

| 边界 | 处理 | 推荐宽度 |
|---|---|---:|
| 深水岸线 | 湿泥、沉积、少量泡沫或油膜 | 0.25–0.60 格 |
| 悬崖坡脚 | 积尘、落石、碎屑带 | 0.20–0.50 格 |
| 废墟边缘 | 黄土覆盖、碎石、破损地坪 | 0.50–1.00 格 |

视觉柔化只隐藏渲染接缝，不扩大、缩小或模糊逻辑格边界。深水和悬崖在默认镜头下必须能在一眼内被辨认为不可通行区域。

## 7. 最小模型清单

| 套件 | 数量 | 格式 | 用途 |
|---|---:|---|---|
| 岩石散件 | 4–6 | `.blend`、`.fbx`、Prefab | 打破 Rocky 平面重复 |
| 废墟模块 | 6–8 | `.blend`、`.fbx`、Prefab | 地坪、瓦砾、钢筋、断管和边缘 |
| 浅水/深水面 | 1–2 | `.blend` 或程序化网格、Prefab | 反光、缓慢流动和岸线表现 |
| 悬崖模块 | 至少 6 | `.blend`、`.fbx`、Prefab | 直段、转角、端头和封口 |
| 能晶节点 | 独立于地表 | 由父规格交付 | 可采集资源节点，不计入 Crystal 地表套件 |

所有地表模型使用 `Y` 向上、`+Z` 正面、导入比例 `1.0`。模型根和拼接基准必须统一；Collider 如有，仅作选择或视觉表面代理。

## 9. 制作顺序

1. 用 `Wasteland` 制作黄金地表样板，先通过无缝、比例、明度和 PBR 通道检查；
2. 从同一荒土母材质派生 `Rocky`、`Wetland`、`Crystal`，保证共同尘土和宏观尺度一致；
3. 制作 Macro、Dust、Wetness 三张共享辅助图；
4. 用测试拼图验证三组软混合，不先制作完整地图；
5. 制作 `Ruins`、`DeepWater`、`Cliff` 贴图及最小几何白模；
6. 固定同一俯视相机、光照和曝光，输出七类单材质图与全部相邻过渡图；
7. Task 13 通过后，另写并批准 Unity 接入计划；
8. 接入后检查默认镜头、旋转、远近缩放、性能、Windows Release 和灰盒回退。

## 11. 验收标准

### 11.1 单张贴图

- 水平、垂直和四角无可见接缝；
- 连续铺设 `4×4` 次后无明显棋盘、十字、重复大石或重复裂纹；
- 默认倾斜正交镜头下仍能辨认类别；
- BaseColor 无固定方向光照，Normal 无翻转，Mask 通道正确，Height 为真实 16-bit；
- 亮度和纹理尺度与 Wasteland 母材质一致；
- 没有文字、Logo、版权水印或来源不明的扫描内容。

### 11.2 过渡

- Wasteland 与 Rocky/Wetland/Crystal 在规定宽度内无硬线、无颜色光环、无法线断层；
- DeepWater、Cliff 和 Ruins 没有方块贴纸感，同时保持规则边界可读；
- 过渡处最多两个主要地表采样，不依赖逐格 GameObject；
- 默认镜头和 1920×1080 下，远景不出现明显重复带或摩尔纹。

### 11.3 最终接入

- 玩法地形、资源节点、移动倍率、阻挡和存档零变化；
- 正式材质关闭后可恢复灰盒；
- 共享材质不产生逐格材质实例；
- 96×64 扩展地图的 Renderer、Draw Call、显存和帧时按真实 Profiler 记录；
- Release Windows 构建无粉色材质、Missing Shader、Missing Script；
- 所有源文件、生成来源、许可证、版本和 Unity 路径可追溯。

## 12. 第一批产出与停止门

第一批只做 `Wasteland` 黄金样板及七类低分辨率风格小样。黄金样板验收后才能把同一模板扩展到其余六类；若无缝、尺度、材质通道或默认镜头可读性失败，先修正样板，不批量生成。

如果制作需要修改地形枚举、逻辑格、稳定 ID、通行规则、资源节点、场景 authoring、URP 全局设置或现有 Build Settings，必须立即停止并提出独立变更，不得以美术接入顺带修改。
