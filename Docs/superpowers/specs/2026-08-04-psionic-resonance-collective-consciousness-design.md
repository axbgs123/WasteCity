# 灵能共鸣与集体意识单城闭环设计

## 目标

完成正式路线图 F1 的灵能路线里程碑：

- 心灵尖塔的灵能攻击产生可观察的精神灼烧/共鸣状态；
- 共鸣目标之间同步承担灵能伤害；
- “集体意识”在只有一座城市的当前版本中提供可验证的共享研究进度；
- 新状态可保存，并兼容旧存档；
- 所有新增表现继续使用程序化占位和稳定美术替换 ID。

本里程碑不实现意识网络建筑、多城市研究共享、灵能机甲、EMP 塔或正式美术。这些分别属于下一建筑里程碑、未来多城市阶段和跨路线桥节点。

## 规则来源与名称

主 GDD 2.9.4 将“精神灼烧、心灵震爆”定义为灵能伤害来源；2.9.5 将灵能路线专属机制定义为“共鸣”：灵能命中标记目标 `5` 秒，任意标记目标受到灵能伤害时，其他标记目标同步承担 `30%`，最多标记 `10` 个目标。

因此本实现把“精神灼烧”作为心灵尖塔的攻击表现，把“共鸣”作为命中后产生的正式规则状态，不额外增加文档未规定的持续伤害。

## 共鸣规则

### 标记

- 心灵尖塔或受控友军对存活敌人造成实际灵能伤害后，为目标施加共鸣。
- 共鸣持续 `5` 秒；再次命中刷新为完整 `5` 秒。
- 同一场景最多同时标记 `10` 个存活、未受控的敌人。
- 达到上限后保留已有十个标记，不替换目标；已标记目标仍可刷新。
- 死亡、精神控制或计时到期立即清除共鸣。
- 没有造成实际伤害时不施加或刷新共鸣。

### 同步伤害

- 当一个已标记目标受到一次由心灵尖塔或受控友军造成的主要灵能伤害时，其他仍有效的标记目标各收到该次实际结算伤害的 `30%`。
- 同步基础值向下取整；主要伤害大于零时同步基础值最低为 `1`。
- 同步伤害仍按 `DamageType.Psionic` 和每个接收者自身护甲、护盾结算。
- 主要目标不额外承担同步伤害。
- 同步伤害不会再次触发同步，避免递归伤害链。
- 死亡和受控目标不会成为同步接收者。

“实际结算伤害”沿用 `HealthModel.Apply` 的返回值，包含被护盾吸收和扣除生命的总量，使共鸣不会绕过既有护盾与伤害矩阵。

## 运行时与占位表现

每个敌人使用独立 `EnemyPsionicResonanceStatus`：

- 保存剩余秒数；
- 负责施加、刷新、清除和计时；
- 通过场景内有效状态数量执行十目标上限；
- 在主要灵能伤害后选择其他有效目标并结算同步伤害。

状态标记使用稳定 ID：

```text
psionics.status.resonance
```

占位表现为敌人上方的紫青色半透明方形脉冲。正式 Sprite 或 Prefab 后续通过 `VisualSlot` 替换，不改变战斗逻辑。

心灵尖塔保持现有 DPS、射程和灵能增幅器消耗，不额外增加伤害或攻速。

## 集体意识的单城市等价效果

GDD 将集体意识定义为“多城市共享部分科技研究进度”。当前版本只有一座城市，因此采用最小等价规则：

- 完成 `core.research.collective-consciousness` 后，新开始的任何未完成研究立即继承其基础时长 `20%` 的共享进度；
- 研究消耗不变；
- 已经进行中的研究不追溯缩短；
- 继承进度只在开始研究时应用一次；
- “思维加速”的 `1.25×` Tick 速度继续独立生效，两者可以叠加；
- 集体意识研究自身不会受自身效果加速。

实现入口为 `ResearchModel.Start` 的可选初始进度比例。`ResearchController` 根据集体意识是否已完成传入 `0.2` 或 `0`。研究界面显示“集体意识：新研究继承 20% 进度”，让规则可以被玩家观察。

该等价规则未来进入多城市阶段时可替换为真实的跨城市共享，不需要迁移已完成研究或新增永久存档字段。

## 存档

存档升级为 schema `28`。

`EnemySnapshot` 新增：

```text
psionicResonanceRemaining: float
```

- schema `28` 恢复未受控敌人的剩余共鸣时间，并限制在 `0..5` 秒；
- schema `27` 及更旧存档默认无共鸣；
- 受控敌人即使快照异常包含共鸣，也恢复为无共鸣；
- 集体意识效果由已完成研究 ID 推导，不增加重复字段；
- 旧存档的研究进度与现有 schema 规则继续保持不变。

## 测试与验收

1. EditMode 覆盖共鸣计时、刷新、无效输入、上限选择和 `30%` 同步值。
2. EditMode 覆盖集体意识的 `20%` 起始进度、未解锁时无效果、消耗不变以及与研究恢复兼容。
3. PlayMode 证明心灵尖塔实际命中会标记目标并创建 `psionics.status.resonance` 占位槽。
4. PlayMode 证明一个标记目标受灵能攻击时，另一个标记目标同步受伤，且同步不递归。
5. PlayMode 证明非灵能塔不会标记，精神控制会清除标记。
6. 存档测试证明 schema `28` 往返剩余时间，schema `27` 使用无共鸣默认值。
7. 运行全部 EditMode、PlayMode、无界面编译和 Windows 64 位构建。
8. 保留真实 Windows 10/11 独立程序冒烟为候选发布门；macOS 开发机不伪造该结果。

## 非目标

- 不增加精神灼烧持续伤害。
- 不让同步伤害再次触发共鸣。
- 不替换现有心灵尖塔数值。
- 不实现意识网络建筑。
- 不实现真实多城市研究共享。
- 不实现灵能机甲、EMP 塔或其他跨路线桥节点。
- 不导入需要许可证确认的正式美术资源。
