# 友军统一规则与集结点设计

## 目标

完成正式路线图 F1 的第一个里程碑：让傀儡、巨兽和被精神操控的敌人遵循同一套目标选择、集结、脱战返回、死亡统计与组织再生规则，并为后续无人机、军队命令和远征系统提供可复用基础。

本里程碑只统一战术行为，不改变三类单位原有的生命、护甲、移动速度、攻击范围、伤害类型和伤害数值。

## 玩家规则

- 默认集结点随移动城市移动，友军继续承担近身护卫职责。
- 玩家把鼠标指向世界位置并按 `Y`，设置一个固定的全局集结点。
- 玩家按 `Shift+Y`，取消固定集结点并恢复随城集结。
- 傀儡、巨兽和心控单位全部响应同一个集结点。
- 友军只攻击进入集结点警戒范围的敌人。
- 追击中的敌人越过最大追击边界后，友军放弃目标并返回集结点。
- 没有有效目标时，友军返回集结点；进入到达容差后停止，避免来回抖动。
- `组织再生`研究完成后，三类友军都缓慢恢复生命。
- 三类友军死亡分别计数，并显示总损失。

## 规则参数

- 警戒半径：`9` 个世界单位。
- 最大追击半径：`13` 个世界单位。
- 集结点到达容差：傀儡和心控单位 `1.25`，巨兽 `1.75`。
- 目标选择：先排除死亡和友方目标，再选择距离当前单位最近、且仍处于警戒/追击规则内的敌人。
- 已有目标只要仍有效且未越过追击边界就继续追击，减少频繁切换。

这些参数由普通 C# 配置和规则模型承载，运行时组件只负责读取场景对象、移动、攻击和显示。

## 结构

### `FriendlyUnitCommandModel`

普通 C# 状态模型，负责：

- 固定集结点是否启用；
- 固定集结点坐标；
- 傀儡、巨兽、心控单位的死亡统计；
- 捕获和恢复可存档状态。

未启用固定集结点时，实际集结位置由运行时控制器读取城市当前位置，不把不断变化的城市位置写进模型。

### `FriendlyUnitTacticalRules`

普通 C# 纯规则，输入单位、集结点、候选目标和战术参数，输出：

- 保持位置；
- 返回集结点；
- 追击目标；
- 在射程内攻击目标。

规则测试覆盖警戒边界、追击边界、无目标返回、到达容差、死亡目标排除和最近目标选择。

### `FriendlyUnitAgent`

统一运行时适配组件，负责：

- 根据单位配置调用战术规则；
- 驱动移动和攻击；
- 应用单位原有伤害类型；
- 应用组织再生；
- 在死亡时向命令模型报告分类损失。

`PlaceholderPuppet`、`PlaceholderBehemoth` 和 `PlaceholderEnemy` 保留各自身份与现有外部 API。傀儡和巨兽把行为委托给 `FriendlyUnitAgent`；敌人成功被心控时动态接入同一个 Agent，并停止敌对行为分支。

敌对单位的友军目标扫描也改为扫描统一 Agent，避免为每种新增友军继续添加独立循环。

### `FormalFriendlyUnitController`

继续作为场景入口，新增：

- 全局命令模型；
- `Y` 与 `Shift+Y` 输入；
- 集结点旗标占位对象；
- 集结状态和损失统计 HUD；
- Agent 注册所需的城市、研究和命令上下文。

## 表现资源

- 集结点使用程序化旗标/菱形占位符，稳定 ID 为 `core.command.rally-point`。
- 傀儡继续使用 `cultivation.unit.puppet`。
- 巨兽继续使用 `biological.unit.behemoth`。
- 心控单位继续使用 `<enemy-stable-id>.controlled`。
- 所有碰撞、生命、攻击和存档逻辑留在玩法组件，不进入美术 Prefab。

未来替换 Sprite、Prefab 或 3D 模型时，不需要修改战术规则。

## 存档

存档 schema 从 `23` 升至 `24`，新增：

- 是否使用固定集结点；
- 固定集结点坐标；
- 三类友军死亡计数；
- 心控单位标记。

旧 schema 加载时：

- 默认恢复为随城集结；
- 死亡统计为 `0`；
- 旧敌人均按原敌对状态恢复。

现有傀儡和巨兽位置、生命与制造/培育进度继续兼容。

## 测试与验收

1. 先写纯规则失败测试，再实现最小规则模型。
2. 增加 PlayMode 测试，证明三类友军都会攻击、返回同一集结点并应用再生。
3. 增加存档 schema `24` 往返和 schema `23` 默认迁移测试。
4. 运行全部 EditMode 与 PlayMode 测试。
5. 执行 Unity 无界面编译、Windows 构建和至少 12 秒独立程序冒烟。
6. 更新路线图的基线提交、测试数量、schema 和完成度。

## 非目标

- 不实现单位选择框、编队或多集结点。
- 不实现守卫/跟随/出征三种军队命令。
- 不实现寻路网格或避障。
- 不制作正式美术、动画和音频。
- 不调整现有单位平衡数值。
