# 《废土移动城市》第一版正式美术样板包设计规格

> 日期：2026-08-08
> 关联需求：`IDEA-0004`
> 需求状态：已明确 / 已批准 / 未实现
> 前置门：3D 建造里程碑 Task 13 通过全部测试、构建、性能与文档验收

## 1. 目标与范围

第一版美术不追求一次替换全部灰盒，而是建立一套可在默认 3D 场景真实运行、可回退、可复用的正式样板。它需要证明：

- 默认倾斜正交俯视镜头下，城市、角色、建筑、地形和 UI 的比例及轮廓清楚；
- 正式模型能够通过稳定视觉槽替换灰盒，而不修改玩法真值；
- 内城 `8×6` 网格、外城世界格、四方向旋转和施工/撤离状态不会因美术资源产生偏移；
- URP 材质、共享纹理、动画、特效和音频可以进入 Release Windows 构建；
- 128 个完成建筑、施工点和遗迹的目标场景保持性能预算；
- 资源来源、许可证、源文件、Unity 路径和验收结果可追溯。

第一版完成后，剩余 23 座普通目录建筑、两个升级目标、敌人、完整战斗表现和四路线批量资源仍保持灰盒或概念状态。完整垂直切片通过前不得扩大为正式资源批量生产。

## 2. 选定美术方向

采用“风格化中低模工业废土”：

- 视觉核心是可以移动并展开的工业城市；
- 以粗壮轮廓、模块化装甲、机械关节、维修痕迹和有限锈蚀表达废土；
- 默认相机距离下先看清功能和类别，再看表面细节；
- 基础建筑使用混凝土、深灰金属、锈色与警示橙黄；
- 科技路线使用蓝白灯光与线性结构；
- 修仙路线使用石/木/金属混合、符文、青绿与金色；
- 生物路线使用甲壳、骨质、暗红与毒绿；
- 灵能路线使用晶体、悬浮构件、蓝紫与品红；
- 不使用写实高密度扫描资产作为主要语言；
- 不直接复制任何参考游戏的具体模型、图标、布局或材质。

## 5. 坐标、比例和模型根规范

- Unity 导入比例固定为 `1.0`；
- `Y` 向上，`+Z` 为正面；
- 静态建筑根节点位于逻辑占地中心，底面为局部 `Y=0`；
- 建筑必须支持 `0°/90°/180°/270°`，视觉主体不得误导实际旋转占地；
- 外城尺寸从 Task 13 最终 `BuildingDefinition` 和旋转占地导出，不在美术阶段重新定义；
- 内城平台精确为 `8×6`，每格 `0.32×0.32`，完整可建表面 `2.56×1.92`；
- 视觉可越过占地的仅限不影响阅读的细天线、烟雾和光效；实体主体、底座与可选择轮廓必须留在批准占地内；
- 模型 Collider 只可作为选择或表面代理，不得决定建造、通行、攻击或存档真值。

## 10. 通用施工与撤离表现

### 10.1 施工套件

按五座样板实际出现的唯一占地制作共享地基和框架，不预设不存在的尺寸。包含：地基、框架、脚手架、焊接点、进度环、暂停图标、材料不足图标和完成闪光。

预览直接复用完成模型和共享透明材质：合法绿色、非法红色。状态色必须兼容 MaterialPropertyBlock。

### 10.2 遗迹和拆除

采用原模型降饱和、共享灰褐材质、裂纹/烧焦贴花和小/中/大通用破损覆盖，不为五座建筑分别重新雕刻完整废墟。

- 遗弃：关闭发光和工作动画，切换遗迹状态，保留占地；
- 完整拆除：显示进度、少量火花、结构分段消退；
- 快速拆除：短促震动、尘土、碎片和快速消失。

交付 `PF_RuinOverlay_{Small|Medium|Large}.prefab`、`MAT_Building_Ruin.mat` 和三类处理 VFX Prefab。

## 11. 环境包

### 11.1 资源节点

铁矿与能晶各提供 LOD0、LOD1、普通、兼容高亮、不兼容、耗尽预留和地面连接底座。稳定节点 ID 继续由运行时生成，Prefab 不保存或推导节点真值。

### 11.2 六种地形

普通、废墟、湿地、岩石、深水、悬崖各提供 `2048×2048` 无缝 BaseColor、Normal 和 URP Mask Map；可选 Height。BaseColor 为 sRGB，其他数据贴图为 Linear。

URP Mask Map：R Metallic、G Occlusion、B Detail Mask、A Smoothness。

### 11.3 十二种装饰

小石、大石、废钢板、破损管道、废弃轮胎、断裂路障、金属箱、损坏路灯、混凝土碎块、机械残骸、干枯植物、能晶碎片。单件 200–2,000 三角面，共享图集和材质，支持 GPU Instancing，不自带玩法碰撞。

- 生产：`MiningStation`、`Smelter`、`Assembler`；
- 物流：`Warehouse`、`AutomatedRepairBay`；
- 防御：`MachineGunTurret`、`LaserTower`；
- 科技：`PowerPlant`；

`HeavyMachineGunTurret` 与 `SwordRidingPlatform` 只作为升级目标保留，不进入这 28 个普通目录图标交付。第一版可以为其制作概念草图，但不得把草图计为已完成的正式图标或模型。

### 12.2 分类、路线和操作图标

- 五类：基础、生产、物流、防御、路线；
- 四路线：科技、修仙、生物、灵能；

源文件使用 SVG 或分层设计源；Unity 版为 `128×128` PNG，提供普通、悬停/激活和禁用所需的可统一着色版本。

### 12.3 菜单组件

十格快捷栏、完整目录、分类标签、路线筛选、搜索框、建筑卡、详情浮层、成本列表、锁定原因、施工进度、取消确认、撤离清单、错误提示、空槽和按钮五态。九宫格面板提供无损 PNG 边框数据，最终进入 Unity SpriteAtlas。

使用有明确商用许可证的中文字体；开发修改器保持工具 UI，不进入正式皮肤范围。

## 13. 特效与音频

八组特效：合法预览、非法预览、选择描边、节点高亮、施工火花、完成、完整拆除、快速拆除。使用 Unity ParticleSystem、URP 材质、PNG 粒子图和必要的简单 Shader Graph，不新增第三方 VFX 包。

十四组音效：菜单开/关、切分类、选建筑、旋转、合法放置、非法放置、施工开始、施工循环、完成、取消、遗弃、完整拆除、快速拆除。源文件统一为 48 kHz、24-bit WAV，以 Mono 为主；Unity 压缩设置由接入阶段决定，不以 MP3 作为源文件。

## 14. 纹理和材质规范

- 建筑常规纹理以 2048 为上限，必要时共享 2048 图集；
- 移动城市可以使用不超过两套 4096 纹理集，需以实际显存记录验收；
- UI 图标和按钮不使用有损 JPEG；
- BaseColor 不烘焙强方向阴影；
- 发光强度在默认 URP 和夜间规范图中可读但不过曝；
- 共享材质必须支持 MaterialPropertyBlock 改色；
- 运行时不得为选择、预览、遗迹或工作状态实例化新材质；
- Shader 与材质必须进入 Release 构建的保留/引用链，Windows 构建不得出现粉色材质。

## 17. 最高效执行顺序

1. Task 13 完成后冻结五座建筑实际占地、稳定槽、相机、城市/领袖替换口和地形槽；
2. 在两天规格周期内完成六张风格图、色板、比例图、命名与材质规则；
3. 只做城市两态、平台、领袖和五建筑白模，立即放入默认镜头验证比例和轮廓；
4. 以采矿站为黄金样板，完整走通概念→白模→比例→细化→UV→贴图→LOD→Prefab→稳定槽→性能→Windows 构建；
5. 黄金样板通过后冻结模型层级、Pivot、LOD、材质、贴图通道、图标场景和 Unity 导入 Preset；
6. 并行三线生产：A 城市/角色/建筑，B 28 图标与建造 UI，C 地形/节点/施工/遗迹/VFX/SFX；
7. 所有模型先以白模进入 Unity，通过占地、旋转、高度、镜头、内外城和 Renderer 验收后才能贴图；
8. 使用固定图标相机批量渲染图标，避免角度、光照和边距漂移；
9. 通过稳定视觉槽替换灰盒，不改任何玩法、schema、存档、占地或资源定义；
10. 在 128 个建筑/施工点/遗迹、菜单打开、预览移动、施工和撤离队列同时存在的场景做性能验收；
11. 构建默认 Release Windows 包，检查 Missing Shader、Missing Script、材质实例、GC、Renderer 和贴图内存；
12. 归档移动、展开、内/外城建造、合法/非法预览、施工、完成、遗弃、两种拆除和菜单总览固定截图；
13. 只有样板包通过并且完整垂直切片随后通过，才批准剩余 23 座建筑和路线资源批量生产。

## 18. 接入与性能验收

样板必须满足：

- 默认 1920×1080 倾斜正交镜头下类别和状态可辨认；
- 五建筑四方向旋转和实际占地一致；
- 内城平台与 `8×6` 表面一致，外城模型与世界格一致；
- 合法、非法、选择、施工、完成、遗迹和两种拆除视觉互不混淆；
- 同场 128 个建筑/施工点/遗迹时没有新增每帧 GC；
- 预览和状态变化不实例化材质；
- 目标为 1080p 60 FPS，实际帧时、Draw Call、Renderer、显存和 Timeline 作为硬件实测记录，不伪装成稳定单元测试；
- Release Windows 构建无 Missing Shader、Missing Script、粉色材质或 Development 修改器泄漏；
- 关闭正式资源映射后能够回退到现有灰盒；
- 自动化测试、场景 authoring、GUID、schema `30` 和 2D 冻结回归保持不变。

## 19. 明确排除

- 剩余 23 座普通目录建筑正式模型；
- `HeavyMachineGunTurret` 与 `SwordRidingPlatform` 正式模型；
- 四路线完整建筑套装；
- 敌人、军队和完整战斗动画/VFX；
- 正式音乐与完整环境音景；
- 多城市、前哨、迷雾和完整生物群系；
- 自定义字体、完整首次引导和可访问性重做；
- 任何玩法、存档、schema、碰撞规则或建筑平衡修改。

## 20. 回退与扩大范围门

所有正式资源通过独立目录和稳定表现映射接入，灰盒资源保留。单项资源失败时只移除该映射并恢复灰盒，不删除规则组件或重写场景基础。

若制作中发现需要修改建筑占地、稳定 ID、玩法 Collider、存档、相机合同、共享材质接口或一实例一主要 Renderer 的当前性能边界，必须停止该资产接入，先提出独立设计变更并获得批准。不得以美术需求直接修改玩法真值。
