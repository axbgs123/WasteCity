# BUG-0006 / IDEA-0012 实施计划

## 目标

在不修改 schema `30`、冻结 2D 或战斗范围的前提下，修复正式 3D 建筑旋转和预览，建立真实仓库共享库存与单资源过滤，补齐石料采集与统一资源图标，并让建造缺料反馈逐项可见。

## 执行顺序

1. **需求与基线**：更新 GDD、路线图、Docs/06、设计与计划；独立提交并普通推送。
2. **BUG-0006 RED**：为方形/矩形建筑补真实 `R` 输入、视觉 yaw、方向箭头、锚点、透明材质和提交一致性失败测试。
3. **BUG-0006 GREEN**：最小修改世界预览、实例变换、菜单状态和场景 authoring；聚焦测试通过后独立审查。
4. **仓储 RED**：为共享 150、内容隔离、过滤、动态可接收容量、原子路由、断网、撤离和不可变快照建立纯规则失败测试。
5. **仓储 GREEN**：新增 `WarehouseStorageState` 与 `CityResourceStorageModel`；接会话生命周期、生产、研究、建造、背包和命令边界；旧 `ResourceInventory` 保留给核心、内部缓存和冻结 2D。
6. **仓库 UI**：真实输入点击仓库打开详情，显示 15 资源内容、总占用/剩余、物流与过滤；过滤命令提交时重验，不让 UI 持有真值。
7. **节点/图标 RED**：锁定 seed `8128` 既有石料节点、Stone 兼容与真实采集；锁定 15 图标映射、世界浮标和全部 UI 消费点。
8. **节点/图标 GREEN**：复用 `ResourceDefinitionCatalog` 建统一图标目录；世界节点使用稳定浮标；更新资源栏、背包、合成、仓库、科技、建造成本和生产详情。
9. **缺料 RED/GREEN**：规则层生成逐项缺口；预览与确认失败共用；覆盖单/多资源和预览过期重验。
10. **整合与性能**：运行相关聚焦测试和 300 次稳定性门；独立静态审查 P0/P1；修复后复跑。
11. **完整验收**：日常完整 EditMode、完整 PlayMode、项目质量门、生成/校验文档、Windows Release 3D、Windows Development 3D、Windows legacy 2D、macOS universal 3D、macOS Player 冒烟。
12. **记录与交付**：在实现提交上执行 `RecordVerification`，更新状态为“已实现待验证”，提交并普通推送；不创建 Release、不合并 PR。

## 文件协作

- 子智能体按“旋转预览”“仓储规则/运行时”“资源节点/图标/缺料”分区；同一时间不修改同一文件。
- 主智能体负责 GDD、Docs/06、跨系统所有权、代码审查、证据核对和最终验收。
- 发现 schema 需求、无法无损处理非空仓库、计划外生产文件或真实规则冲突时停止并报告。
