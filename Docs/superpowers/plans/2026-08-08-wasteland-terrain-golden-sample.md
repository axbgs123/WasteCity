## 2. 精确视觉描述

`Wasteland` 是七类地表的视觉母材质：暖黄、干燥、被工业尘土长期覆盖的压实荒地。默认倾斜正交镜头下，第一眼读到的是宽阔、安静、低起伏的赭黄土块；第二层是柔和风积尘带和零散小砾石；只有近看才出现稀疏浅裂纹、极弱车辙、锈色污染与旧工业痕迹。

画面不得有固定方向日照、高光、投影或环境光遮蔽被烘焙进 BaseColor。裂纹不能形成龟裂网格，砾石不能形成周期性圆点，车辙不能贯穿整张纹理形成道路。约 70% 的视觉信息位于中低频，微观噪声只负责近看材质感。连续铺设后应像同一片自然风化地表，而不是重复地砖。

它必须保留足够的暖黄尘土成分，使后续 `Rocky`、`Wetland`、`Crystal` 和 `Ruins` 能自然接回母材质。`Crystal` 地表及 `ResourceNodes/EnergyCrystal` 可采集能晶节点不属于本样板；本文件也不得承载任何资源或玩法真值。

## 3. 色彩比例与锚点

### 3.1 构成比例

| 成分 | 目标面积 | 黄金样板验收容差 |
|---|---:|---:|
| 压实赭黄土 | 65% | ±5 个百分点 |
| 浮尘与风积层 | 18% | ±4 个百分点 |
| 小砾石 | 10% | ±3 个百分点 |
| 浅裂纹 | 4% | ±2 个百分点 |
| 车辙、锈色污染或旧工业痕迹 | 3% | ±2 个百分点 |

构成遮罩总和必须为 100%。容差只允许自然边缘混合，不允许通过大面积均匀噪声掩盖比例偏差。

### 3.2 sRGB 色锚

| 用途 | sRGB Hex | 使用规则 |
|---|---|---|
| 压实荒土 | `#66513A` | 主要暗土基准，支撑低频大块 |
| 风化黄土 | `#887054` | 主要暖色表面和浮尘高值 |
| 深层土与裂隙 | `#3D342B` | 只用于浅裂纹、砾石间隙与少量压痕 |
| 锈色污染 | `#8A4D28` | 局部点缀，总面积纳入 3% 工业痕迹 |

上述色值是锚点而非纯色填充。局部明度和色相变化必须来自材质构成遮罩，不能依靠烘焙灯光；整体保持暖黄赭色，避免鲜橙、纯黑、饱和红或大片冷灰抢占母材质。

## 4. 纹理尺度

一套 2048×2048 纹理覆盖外城约 4×4 个逻辑格，即约 512 px/格。黄金样板按以下世界阅读尺度制作：

| 特征 | 典型跨度 | 2048 贴图上的参考像素 | 视觉职责 |
|---|---:|---:|---|
| 压实土低频色块 | 0.5–1.5 格 | 256–768 px | 远景主形状 |
| 风积尘带 | 0.2–0.8 格 | 102–410 px | 中景柔和变化 |
| 小砾石单体 | 0.015–0.06 格 | 8–31 px | 近景材质感 |
| 浅裂纹长度 | 0.15–0.65 格 | 77–333 px | 稀疏局部破损 |
| 浅裂纹宽度 | — | 2–8 px | 不形成黑色沟槽 |
| 弱车辙/工业痕迹 | 0.5–1.5 格 | 256–768 px | 极弱方向暗示 |

宏观特征不得刚好等于一格、两格或贴图半宽，避免与逻辑格和 4×4 平铺周期产生棋盘。旋转 0°、90°、180°、270° 后，纹理不得暴露唯一方向。

## 5. PBR 通道参数

### 5.1 BaseColor

- 8-bit RGB/RGBA PNG，2048×2048，嵌入或明确标记 sRGB；
- 不含固定方向光照、阴影、镜面高光、AO 或深度伪影；
- Alpha 如未使用必须为 1，不把玩法或混合权重藏在 Alpha 中。

### 5.2 Height

Height 必须先于 Normal 定稿，使用 16-bit 灰度 Linear 数据，黑低白高：

| 成分 | 建议归一化高度 |
|---|---:|
| 压实土基面 | 0.46–0.52 |
| 浮尘与风积层 | 0.52–0.60 |
| 小砾石 | 0.56–0.70 |
| 浅裂纹 | 0.34–0.45 |
| 弱车辙/工业压痕 | 0.40–0.48 |

整体不得低于 0.22 或高于 0.82，以保留后续混合余量。Height 只描述表面微起伏，不制造悬崖、深坑或玩法阻挡。

### 5.3 Tangent Space Normal

- 8-bit RGB PNG，2048×2048，Linear；
- 从批准的 16-bit Height 与独立细节遮罩生成，再进行人工清理；
- 默认法线朝向正确，无反转、断边、压缩块或色彩空间污染；
- 起伏保持钝、低、宽，小砾石可读但不呈尖刺；
- 不允许仅对 BaseColor 灰度化后直接套滤镜作为最终 Normal。

### 5.4 URP Mask

| 通道 | 内容 | 目标范围与规则 |
|---|---|---|
| R | Metallic | 基础土、尘、砾石为 `0.00`；极少旧金属污染点可到 `0.05`，覆盖率低于 1% |
| G | Ambient Occlusion | 大部分 `0.78–1.00`；裂纹和紧密砾石间隙可到 `0.65–0.82`，不得用重黑 AO 伪造深度 |
| B | Detail Mask | 压实土 `0.45–0.70`，浮尘 `0.20–0.45`，砾石/裂纹 `0.70–1.00`；只控制后续细节响应 |
| A | Smoothness | 总体 `0.12–0.25`；浮尘/裂纹 `0.10–0.16`，压实土 `0.14–0.22`，砾石 `0.18–0.25` |

Mask 为 8-bit RGBA PNG、2048×2048、Linear。四个通道必须分别检查，不允许用同一灰度图复制四次。

## 6. 工具与生成方法

### 6.1 首选工具链

| 工具 | 固定用途 | 版本策略 |
|---|---|---|
| Krita | 分层构图、遮罩绘制、BaseColor 清理、接缝修复 | 5.2.16 |
| Blender | 周期性节点、Height/Normal/Mask 的可重复生成，以及固定倾斜正交视角、PBR 平面/球体检查与离线渲染 | 5.2.0 LTS，build hash `fbe6228777e7`；预览使用 EEVEE，Cycles 已启用 |
| Python、NumPy、Pillow | PNG 尺寸、位深、通道、周期接缝与数值范围检查 | Python 3.12.13、NumPy 2.3.5、Pillow 12.2.0 |
| Git + Git LFS | 版本、来源记录和大文件追踪 | 使用仓库现有规则，不修改 `.gitattributes` |

如果首选工具不可用，可以更换等价工具，但必须先在资产记录中说明原因、确切版本、输出差异和可重复步骤；不得为安装工具修改 Unity Packages 或项目设置。

### 6.2 制作方法

1. 先建立五类构成的周期性黑白遮罩，使四边与四角天然连续；
2. 以低频压实土和风积尘决定主构图，再加入稀疏砾石、裂纹和工业痕迹；
3. BaseColor 只根据材料色与自然色差生成，不混入光照；
4. Height 独立表达真实微起伏，不能由 BaseColor 明度直接复制；
5. Normal 从 Height 和高频细节派生，人工检查方向及强度；
6. Mask 四通道按物理属性分别制作并打包；
7. 使用 Offset/Wrap 工作流逐边修复，随后做 4×4 和四向旋转检查；
8. 在固定中性光照、固定曝光下输出倾斜正交预览和 PBR 检查图。

AI 生成仅可在来源与许可证明确时作为情绪参考，不得直接成为正式像素来源。扫描、照片、笔刷和第三方噪声库同样必须可追溯并允许项目用途；无法证明时只能使用原创程序化形状和项目自制笔刷。
