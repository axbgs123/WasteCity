# A 卷：首版 Demo 执行设计

## A0. 文档使用说明

本文件是项目唯一主设计文档。A 卷用于指导首版 Demo 的实际制作、测试与验收；B 卷保留原始正式版世界观、系统、内容库和长期设想。后续开发不应只删除暂缓功能，而应更新其状态、依赖和验证结论。

### A0.1 范围状态

| 标记 | 含义 |
|------|------|
| **D1-实装** | 首版 Demo 必须真正开发，并参与核心玩法 |
| **D1-简化** | 保留玩家体验，但采用固定内容或简化规则实现 |
| **D1-预告** | 只通过界面、文本、演出或结尾展示 |
| **正式版** | 完整设计保留在 B 卷，首版 Demo 不开发 |

### A0.2 强制扩展原则

首版减少的是内容数量，不是系统扩展能力。

- 资源、建筑、敌人、命轨、科技、领袖、事件均采用数据驱动；
- 新增同类内容原则上通过配置接入，不修改核心流程代码；
- 首版固定事件同样使用通用事件条件，不直接写死在场景脚本中；
- 系统间通过明确的输入、输出和事件通信，避免互相读取内部状态；
- 每项配置使用带命名空间的稳定 ID，不以显示名称作为逻辑键；
- 所有玩家可见文字使用本地化 Key，不在规则代码中写中文显示文本；
- 存档按版本号和系统模块组织，为后续字段迁移预留空间；
- Demo 专用演出可以定制，但不能绕过资源、战斗、科技等核心规则伪造结果。

扩展接口按两级处理：

- **首版必须保留的内容扩展**：资源、建筑、敌人、科技、命轨、角色、事件；
- **首版只避免堵死、不提前抽象的规模扩展**：多城市、跨星球、外交、继承政治、复杂运输。

原则是“内容扩展现在做，规模扩展以后做”。没有首版调用者的抽象层不得仅因正式版设想而提前开发。

### A0.3 AI 执行边界

向 AI 分派首版开发任务时，必须附带以下约束：

> 只以 A 卷为当前版本需求。B 卷只用于理解正式版背景；除非任务明确引用，否则禁止实现 B 卷功能。A、B 冲突时执行 A 卷。不得自行增加系统、资源、敌人、建筑或技术架构。

每次任务只提供当前功能所需章节和依赖，避免将整份 B 卷作为无差别实现上下文。

## A1. 产品定义

### A1.1 一句话介绍

一款 2D 俯视角移动城市游戏。玩家驾驶前代文明留下的城市残骸穿越废土，在资源点展开生产与防御；发展越快，越容易引起未知存在的关注，迫使玩家在坚守与转移之间持续决策。

### A1.2 Demo 产品目标

1. **玩家目标**：首次 30-40 分钟内体验完整的“移动→展开→生产→防守→坚守或撤离→升阶”循环，并产生继续探索正式版的欲望。
2. **作品集目标**：展示产品定位、用户体验、版本范围、系统拆解、数值设计、AI 生产管理、测试和迭代能力。
3. **正式版目标**：Demo 是可继续扩建的纵向切片，不是完成后全部推翻的一次性原型。

### A1.3 目标玩家

- 喜欢《Mindustry》《Thronefall》《Factorio》等生产、建造或塔防游戏的 PC 玩家；
- 喜欢废土、文明成长与幕后危机叙事的玩家；
- 能接受中等学习成本，但希望开局数分钟内获得明确操作反馈的玩家。

### A1.4 时长目标

- 首次完整体验：30-40 分钟；
- 熟练玩家：20-25 分钟；
- 不通过强制等待、重复波次或压低生产速度凑时长；
- 通关后允许继续游玩当前地图，但不再解锁正式版后续主线。

### A1.5 核心体验支柱

1. **城市就是角色**：城市能移动、碾压、展开、受伤和撤离，不是普通基地。
2. **生产服务战斗**：生产线必须直接改变防御能力，资源瓶颈必须可观察。
3. **力量引来目光**：建造、研究、命轨和升阶会提高关注度。
4. **命轨改写规则**：命轨改变布局、经济或时间规则，而非普通数值 Buff。
5. **世界存在异常**：Demo 只制造怀疑和悬念，不一次讲完全部世界观。

### A1.6 首版非目标

- 不验证多星球、多城市、外交、继承政治和完整四路线；
- 不追求无限重玩、完整沙盒或正式版内容量；
- 不以底层技术复杂度作为首要卖点；
- 不为了系统齐全牺牲可理解性和完成度；
- 不要求所有玩家必须玩满 40 分钟。

## A2. 核心循环

### A2.1 长循环

```text
移动探索
  → 发现资源与风险
  → 选择展开位置
  → 建造生产与防御
  → 获取力量并提高关注度
  → 应对定向攻击
  → 收起转移或继续坚守
  → 在新区域重复并完成文明升阶
```

### A2.2 中循环

约 5-10 分钟：

```text
发现矿区 → 展开生产 → 扩建防线 → 承受怪潮 → 回收或转移
```

### A2.3 短循环

约 30-60 秒：

```text
击杀或采集 → 获得资源 → 建造或补充弹药 → 防御能力提高
```

### A2.4 核心设计假设

以下结论尚未被试玩证明，必须进入测试：

- 移动城市比固定建城更有趣；
- 展开收益与暴露风险能够形成真实取舍；
- 玩家能理解生产瓶颈并愿意主动扩产；
- Boss 阶段的坚守与撤离都是合理解法；
- 命轨能够显著改变玩家策略；
- 生产、领袖和塔防操作不会造成过高认知负担。

## A3. 六幕体验流程

### A3.1 第一幕：遗产苏醒（0-3 分钟）

**玩家目标**：理解城市能移动、碾压怪物并回收尸体。

- 100 名幸存者意外激活上一循环留下的移动城市；
- 遗产系统弹出三条命轨，玩家三选一；
- 城市开始缓慢移动，引导玩家使用 WASD；
- 玩家碾过“啃噬者”，尸体转化为生物质；
- 控制台从乱码中出现少量可读文字，暗示城市并非当前文明制造。

**验收**：

- 开局 30 秒内完成第一次有效操作；
- 90 秒内获得第一次资源；
- 玩家知道移动城市本身也是武器。

### A3.2 第二幕：寻找落脚点（3-7 分钟）

**玩家目标**：在资源收益、敌人密度和位置安全之间做第一次选择。

- 地图提供安全但贫瘠的浅层铁矿；
- 同时提供怪物更多、产量更高的结晶裂谷；
- 驶近后自动扫描矿脉；
- 玩家可以立即展开，也可以继续探索；
- 扫描与长时间停留会轻微提高关注度。

**范围**：

- 固定地图骨架：**D1-简化**；
- 资源、巡逻怪和非主线遗迹局部随机：**D1-实装**；
- 完整程序化世界：**正式版**。

### A3.3 第三幕：第一次展开（7-11 分钟）

**玩家目标**：理解移动与展开两种状态的收益和限制。

- 玩家启动展开，城市进行约 5 秒变形；
- 展开后出现建筑网格，移动能力关闭；
- 城市自带仓库、住房和三段残破城墙；
- 玩家建造第一座采矿站；
- 少量游荡怪靠近，城市核心的低效自卫武器暂时兜底。

**验收**：

- 展开后 60 秒内看到铁矿产量变化；
- 玩家能够找到建造入口；
- 第一次展开不因 8 秒纯等待破坏节奏。

### A3.4 第四幕：生产服务战斗（11-20 分钟）

**玩家目标**：建立第一条完整、可观察的生产链。

```text
采矿站 → 铁矿 → 冶炼厂 → 合金 → 装配厂 → 弹药 → 机枪塔
```

- 城市物流范围内自动共享资源；
- 建筑显示输入、输出、库存、效率和阻塞原因；
- 第一座塔建成后立即出现小规模怪群；
- 初始弹药保证塔可立即射击，但无法长期跳过生产；
- 第二座塔制造明显弹药压力，推动玩家扩产。

**验收**：

- 玩家能够回答“为什么缺弹药”；
- 玩家知道增加哪种建筑能解决当前瓶颈；
- 2 座采矿站的完整生产链可稳定支持 1 座持续射击的机枪塔。

### A3.5 第五幕：关注与领袖（20-29 分钟）

**玩家目标**：理解发展速度会转化为外部压力。

- 建造、研究和命轨使用推动关注度达到首次阈值；
- 领袖候选人“岑烬”通过求救事件出现；
- 玩家可以立即救援，牺牲矿区发展时间；
- 也可以先扩充防御，使岑烬受伤并降低 Boss 战技能效果；
- 岑烬加入后提供一个主动技能和一个城市被动；
- 第一轮定向攻击开始，加入重甲与远程敌人。

**验收**：

- 玩家因为资源或时间不足放弃一部分收益；
- 救援选择产生可感知、但不锁死流程的结果；
- 玩家开始怀疑怪物在针对生产设施。

### A3.6 第六幕：坚守、撤离与升阶（29-40 分钟）

**玩家目标**：在高潮中回收移动城市、生产、关注度和命轨四个核心设计。

- 关注度达到第二阈值；
- Boss“晶壳母体”带领怪潮出现；
- 玩家可留在原阵地，用生产线持续供弹；
- 也可收起城市，牺牲部分外围建筑或资源，转移到有利地形；
- 两种方案均可通关，但结算评价不同；
- 击败 Boss 后满足文明升阶条件；
- 玩家主动升阶，命轨升级一次；
- 升阶信号被未知存在捕捉，触发结尾扫描；
- 结算后可继续游玩当前地图。

**验收**：

- 坚守与撤离均通过内部测试；
- 玩家至少考虑过一次城市转移；
- 结尾同时完成战斗高潮、系统回收和叙事悬念。

### A3.7 事件触发接口

六幕由统一事件条件驱动，支持：

- 游戏时间；
- 资源数量；
- 建筑状态；
- 科技状态；
- 击杀和敌人状态；
- 地图位置；
- 关注度；
- 人口与生产力；
- 前置事件与玩家选择。

事件结果支持资源、人口、关注度、建筑、科技、角色状态、对话和后续事件，不把分钟数写成唯一触发条件。

## A4. 首版系统规格

### A4.1 系统范围总表

| 系统 | 首版 Demo | 首版不开发 | 扩展接口 |
|------|-----------|------------|----------|
| 移动城市 | 移动、碾压、展开、收起、受伤 | 多城市、模块更换、跨星球移动 | 状态、参数、模块槽和状态效果配置化 |
| 地图 | 固定骨架、局部随机、迷雾、两类地形 | 完整程序化、多星球、小世界 | 地形、资源、遭遇使用统一地图节点 |

| 关注度 | 0-100、两个攻击阈值、原因记录 | 150+ 天劫、多城打击、三派博弈 | 来源和阈值事件使用规则表 |

| 领袖 | 1 名固定角色、主动和被动 | 随机天赋、继承、忠诚、叛变 | 属性、技能、城市修正和事件身份配置化 |

| 存档 | 自动检查点、退出保存、重开 | 多槽位、云存档、跨循环继承 | 模块化存档和版本迁移 |
| 设置 | 音量、分辨率、全屏、震动、操作说明 | 完整重映射、手柄、无障碍套件 | 统一设置项和输入动作映射 |

### A4.2 移动与展开

```text
移动中 → 展开中 → 已展开 → 收起中 → 移动中
                  ↓
                 摧毁
```

- 移动中可探索、碾压小怪、回收尸体；
- 移动中不能建造、研究或运行长周期工业生产；
- 展开中与收起中允许取消，但损失部分进度；
- 已展开时开放网格、生产、研究和完整防御；
- 城市内置建筑自动保留；
- 外围建筑需回收，否则留在原地；
- 受到攻击时可以收起，但速度降低；
- 建筑数据包含内置、可折叠、不可折叠、可回收标签。

### A4.3 地图与探索

首版地图约为单屏面积的 12-16 倍，包含：

- 出生区；
- 安全矿区；
- 高收益结晶裂谷；
- 领袖求救区；
- Boss 区域；
- 2-3 个非主线探索点。

主流程区域位置稳定，随机资源点具体坐标、小怪巡逻、非主线遗迹和部分障碍。

### A4.4 资源与生产

```text
铁矿 → 合金 → 弹药 → 机枪塔
怪物尸体 → 生物质 → 维修 / 救援 / 命轨代价
```

- 每种基础原料至少拥有两个用途；弹药等明确服务单一系统的中间品可以只有一个最终用途，但其产销瓶颈必须可见；
- 生产停滞显示缺料、输出已满、不在物流范围等原因；
- 首版不制作电力系统；
- 正式版能晶、水源、石材和路线资源保留在 B 卷；
- 数值全部进入配置表，不写入代码。

### A4.5 建筑与物流

- 使用方格网格；
- 展开后城市提供基础物流范围；
- 范围内建筑自动访问城市库存；
- 不要求建筑彼此相邻；
- 仓库扩大库存，但首版不扩大物流距离；
- 拆除返还 80% 建造资源；
- 战斗中拆除需要读条；
- 建筑可以暂停运行；
- “相邻 8 格同类建筑共享”保留为正式版可选物流规则，不在首版启用。

### A4.6 战斗

首版护甲标签：

- 无甲；
- 重甲；
- 特殊。

首版伤害：

- 物理伤害；
- 城市碾压；
- 领袖技能伤害。

B 卷的五伤害×五护甲矩阵完整保留，但不在首版实现。只有一条完整科技路线时，五系克制不能形成有效配装选择。

必要反馈：

- 命中闪白或受击动作；
- 伤害数字合并；
- 射击、命中、死亡、回收、建筑受损使用可区分音效；
- 重甲单位提供低效反馈；
- Boss 攻击带范围预警；
- 失败后 10 秒内可从最近检查点重试。

### A4.7 关注度

首版玩家层名称为“关注度”，世界内名称为“异常观测值”。

| 数值 | 状态 | 效果 |
|------|------|------|
| 0-29 | 未锁定 | 游荡怪，偶发扫描噪声 |
| 30-59 | 异常回波 | 第一次定向攻击 |
| 60-89 | 定向观测 | 精英和远程敌人加入 |
| 90-100 | 坐标锁定 | Boss、异常扫描 |

来源包括关键建筑、科技、强力命轨、救援和文明升阶。挂机不会自然增加关注度。界面显示最近三条变化原因，为“因果透明”命轨保留完整解释层。

### A4.8 命轨

首版三条：

1. **袖珍宇宙**：每类首座生产建筑效率×2；强化建筑被毁时产生范围坍缩。
2. **虚空债**：资源不足时允许透支建造；债务使关注度持续增长，获得资源后自动还债。
3. **回溯锚点**：设置并回到一个锚点；世界状态回退，但关注度保留并额外增加。

命轨数据保留 1-9 级效果、触发器、代价、规则替换和专属 UI 字段。

### A4.9 科技与升阶

首版科技：

```text
废料加工
├─ 基础冶金：解锁冶炼厂
├─ 弹药装配：解锁装配厂
├─ 自动防御：解锁机枪塔
├─ 加固结构：提高城市与城墙耐久
└─ 遗产解析：满足升阶条件之一
```

首版升阶必须同时满足：

- 完成“遗产解析”；
- 建造至少 2 座机枪塔；
- 击败晶壳母体；
- 城市仍有至少 1 座生产建筑运行。

不采用原始“任一条件即可”的方式，避免玩家绕过主要体验。

### A4.10 领袖

首版角色：**岑烬**，废土维修队负责人，带领约 40 名幸存者。

- 主动“强制过载”：附近炮塔短时间提高攻速，结束后短暂停火；
- 立即救援时攻速×1.75，延迟救援时攻速×1.35，持续 5 秒，结束后停火 3 秒，冷却 30 秒；
- 被动“应急装配”：城市物流范围内装配厂效率×1.25；
- 立即救援：健康加入；
- 延迟救援：受伤加入，Boss 战主动效果降低；
- 救援失败不永久删除角色，避免首版核心内容丢失；
- 角色重伤后暂退，不发生永久死亡。

### A4.11 失败、检查点与结算

失败条件：

- 移动城市核心耐久归零；
- Boss 事件中城市和关键领袖同时失去战斗能力。

检查点：

- 命轨选择完成；
- 第一次展开完成；
- 首座机枪塔建成；
- Boss 事件开始。

结算显示：

- 完成时间；
- 击杀数量；
- 最高关注度；
- 生产效率；
- 建筑损失；
- 救援与坚守/撤离选择；
- 正式版系统预告。

## A5. 人口与城市生产力

### A5.1 首版人口

首版人口不通过 30 分钟内的自然生育增长，而通过救援幸存者增加。

- 初始人口：100；
- 初始容量：150；
- 住房：容量 +50；
- 可选遗迹救援：人口 +20；
- 岑烬救援：人口 +40；
- 正常通关人口：140-160。

### A5.2 生产力公式

```text
生产力倍率 = 50% + 当前人口 × 0.5%
首版上限 = 250%
实际建造时间 = 基础建造时间 ÷ 生产力倍率
```

| 人口 | 生产力 |
|------|--------|
| 100 | 100% |
| 120 | 110% |
| 140 | 120% |
| 150 | 125% |
| 160 | 130% |
| 200 | 150% |
| 400 | 250%（达到首版上限） |

首版生产力影响：

- 建筑建造；
- 建筑拆除；
- 城市展开与收起；
- 战后建筑维修。

首版生产力暂不直接影响采矿、冶炼和装配速度，防止人口同时放大全部经济环节。后续使用统一修正来源：

```text
城市生产力
├─ 人口：D1-实装
├─ 领袖：正式版
├─ 科技：正式版
├─ 士气：正式版
├─ 城市模块：正式版
├─ 环境地形：正式版
└─ Buff / Debuff：正式版
```

每个修正项包含来源 ID、作用对象、加成方式、数值和持续时间。建筑逻辑不能直接读取人口。

## A8. Demo 叙事

### A8.1 叙事目标

Demo 只需让玩家知道：

1. 城市来自前代文明；
2. 灾难和怪潮可能并非自然形成；
3. 文明升阶后，玩家被某种存在确认。

Demo 不直接解释联邦完整历史、高维玩家、监察者名称、三派、白点预言、循环次数和升维条件。

### A8.2 信息揭示

**开局**：城市控制台原本是乱码；命轨选择后，部分内容变为可读，而幸存者看不见玩家看到的完整界面。

**中段**：怪物定向攻击生产节点；遗迹中的灾难周期过于精确；攻击前出现无法追踪来源的倒计时。

**结尾**：升阶后天空出现规则扫描，系统截获：

> “异常变量确认。遗产响应程度：超出历史样本。”

随后被未知信息覆盖：

> “它们已经看见你了。下一次，不会只派这些东西。”

### A8.3 正式版愿景预告

- 科技、修仙、血肉、灵能四路线；
- 单城发展为多城市网络；
- 行星扩展到恒星系；
- 监察者三派的模糊剪影；
- 逃离、反抗、升维、联合文明等结局方向。

预告只展示 B 卷已有设计，不增加无法兑现的新功能。

## A15. 已知不足与后续验证

1. 核心移动是否比固定建城有趣，必须试玩验证；
2. 收起时建筑和资源损失强度尚需平衡；
3. 生产、塔防和领袖操作可能造成认知过载；
4. 固定骨架与局部随机的重玩价值有限；
5. 三条命轨强度可能不平衡；
6. 坚守与撤离可能存在明显最优解；
7. AI 生成美术的一致性和商用授权需要持续管理；
8. 两周周期最容易低估 Unity 集成和 Bug 修复；
9. 世界观完整，但首版人物情感抓手仍依赖岑烬单一角色；
10. 正式版“持久世界”和“肉鸽”的关系尚未完全定义；
11. 多城市、外交、政治、四路线、多星球同时存在，正式版长期范围风险极高；
12. A 卷数值是测试基线，不能未经试玩直接视为最终平衡。
13. 正式开放 Mod 后会形成长期 API、存档和兼容维护成本，不能在核心玩法未稳定时承诺脚本 Mod。

### A16.8 Boss 规格

**阶段一：100%-70%**

- 每 12 秒召唤 2 个啃噬者；
- 每 10 秒使用一次地面冲击，预警 1.5 秒，造成 60 伤害；
- 缓慢接近城市核心。

**阶段二：70%-40%**

- 获得 600 点结晶护盾；
- 护盾存在时本体物理减伤提高至 50%；
- 召唤 3 个啸叫者；
- 每 14 秒制造持续 6 秒的结晶危险区。

**阶段三：40%-0%**

- 移速提高 40%；
- 每 15 秒向城市核心进行一次冲锋，预警 2 秒；
- 每 10 秒召唤 3 个啃噬者；
- 不再恢复结晶护盾。

撤离路线在 Boss 战开始后开放。Boss 追踪移动城市，但不会穿越预设结晶障碍；玩家可以利用地图地形争取重新展开时间。

- 安全矿区位于出生区东北；
- 结晶裂谷位于地图中央偏北；

- 撤离有利地形位于东部狭口；
- 主路线总移动距离控制在 3-5 分钟；

### A17.2 第 4 天核心门

第 4 天结束必须亲自连续玩灰盒核心闭环至少 20 分钟，并回答：

- 移动是否具有操作价值，而不只是赶路；
- 展开位置是否影响生产和防御；
- 弹药瓶颈是否清晰；
- 收起是否产生紧张决策；
- 城市碾压是否有爽感但不过强。

如果三项以上答案是否定的，第 5 天不增加新功能，优先修正核心闭环。

### A17.3 功能冻结

第 10 天起：

- 禁止增加新资源、建筑、敌人、命轨和系统；
- 只允许修复、调数值、替换素材和改善反馈；
- 任何新想法进入正式版待办，不直接进入首版；
- 阻断流程问题优先于画面细节；
- 打包版本问题优先于编辑器专用体验。

### A17.4 AI 任务验收

每个 AI 任务必须：

- 对应一个可观察的玩家价值；
- 明确只能修改的目录或系统；
- 提供数据配置示例；
- 提供正常和边界测试步骤；
- 说明存档兼容影响；
- 说明新增扩展点的当前调用者；
- 由开发者在 Unity 场景和打包版本中亲自验收。

AI 生成代码不得因“未来可能用到”自行引入 ECS、大型依赖注入框架、联网框架或完整多城架构。

## A18. 试玩验证方案

### A18.1 测试轮次

| 轮次 | 时间 | 样本 | 目的 |
|------|------|------|------|
| R0 自测 | 每日 | 开发者 | 功能正确、核心节奏、明显 Bug |

测试者优先选择：

- 1/3 熟悉工厂或塔防；
- 1/3 普通 PC 游戏玩家；
- 1/3 对复杂系统不熟悉的玩家。

### A18.2 观察记录

测试过程中不主动教学，只记录：

- 第一次停顿超过 10 秒的位置；
- 第一次打开错误界面的位置；
- 是否知道当前目标；
- 是否理解建筑缺料；
- 是否注意到人口和生产力；
- 是否查看关注度原因；
- 第一次防线失败的原因；
- Boss 阶段是否考虑收起；
- 命轨是否实际改变行为；
- 主动表达兴奋、困惑或无聊的位置；
- 每幕实际完成时间；
- 崩溃、卡死、存档和严重性能问题。

### A18.3 事件记录

首版使用本地测试日志，不需要联网分析服务。至少记录：

### A18.4 访谈问题

试玩后按顺序提问，不提前透露标准答案：

1. 你觉得这个游戏最特别的地方是什么？
2. 你刚才主要在解决什么问题？
3. 哪个时刻最有成就感？
4. 哪个时刻最困惑或最无聊？
5. 你为什么选择坚守或撤离？
6. 你的命轨改变了哪些做法？
7. 关注度在你看来代表什么？
8. 如果继续玩，你最想解锁什么？
9. 哪个系统你认为可以删除？
10. 你愿意再次游玩吗？为什么？

### A18.5 决策阈值

| 现象 | 处理 |
|------|------|
| 超过 20% 测试者 1 分钟内不会移动 | 重做开局镜头、提示和输入反馈 |
| 超过 20% 在 8 分钟前无法展开 | 缩短探索、强化目标标记 |
| 超过 30% 不懂弹药瓶颈 | 重做建筑状态、资源流向与提示 |
| 超过 50% 不注意人口生产力 | 提高效果或减少首版曝光权重 |
| 超过 70% Boss 选择同一路线 | 调整坚守/撤离成本，消除明显最优解 |
| 超过 30% 因缺弹药首次失败 | 增加初始弹药或延后第一轮压力 |
| 超过 20% 在第 15-25 分钟表达无聊 | 压缩生产等待或提前领袖事件 |
| 多数玩家说不出“移动城市” | 核心定位失败，暂停外围内容开发 |

## A19. 产品定位与竞品差异

### A19.1 定位表达

首版对外类型描述：

> 移动基地 × 自动化生产 × 塔防经营 × 规则选择

首版不将“多星球文明”“完整肉鸽”“割草”作为已实现卖点。这些只能作为正式版方向，避免玩家和面试官产生错误预期。

### A19.2 用户需求

| 用户需求 | 本作回应 |
|----------|----------|
| 建造系统能产生可观察结果 | 生产链直接供给炮塔弹药 |
| 防守不能只有堆数值 | 选址、物流、领袖、碾压与撤离共同决定结果 |
| 基地经营不能长期静止 | 资源枯竭和关注度推动迁移 |
| 随机选择需要改变玩法 | 命轨改变布局、经济或时间规则 |
| 世界观需要由玩法表达 | 关注度和针对性攻击表现“被观察” |

### A19.3 竞品功能对照

| 作品 | 主要借鉴 | 本作不照搬 | 本作差异 |
|------|----------|------------|----------|
| Mindustry | 生产直接服务防御、资源瓶颈可视 | 不在首版制作复杂传送带网络 | 整座城市可移动并主动撤离 |
| Thronefall | 紧凑的建造与战斗节奏 | 不采用严格昼夜两阶段 | 压力由关注度与玩家行为触发 |
| Factorio | 工业可读性、自动化反馈 | 不追求首版超大工厂和物流复杂度 | 生产线随移动城市承担迁移风险 |
| 吸血鬼幸存者 | 低门槛战斗反馈和规则级构筑感 | 不把角色自动攻击割草作为唯一玩法 | 命轨同时作用于城市经营与风险 |
| 文明 6 | 文明成长、科技与多城愿景 | 不在首版实现回合制宏观管理 | 以实时城市生存验证文明起点 |
| RimWorld | 角色事件和涌现叙事 | 不在首版实现复杂人物模拟 | 固定领袖服务于核心流程抉择 |

### A19.4 核心差异化验证

差异化不能只写在文档中，必须通过试玩满足：

- 玩家会因为生产与关注度主动改变城市位置；
- 坚守和撤离不是剧情按钮，而是由当前布局与库存决定；
- 命轨会导致不同的建造或风险选择；
- 玩家在不知道完整世界观时，也能从系统行为感到“被观察”。

若多数玩家只将其描述为“普通塔防加一个会移动的基地”，说明核心差异尚未成立。

## A20. Mod-ready 与内容扩展设计

### A20.1 当前目标

首版目标是 **Mod-ready**，不是 **Mod-supported**。

| 能力 | 首版目标 |
|------|----------|
| 开发者在 Unity 内增加内容 | D1-实装 |
| 玩家编辑外部数据增加内容 | 正式版早期 |
| 玩家加载图片、音频、预制体 | 正式版中期 |
| Steam Workshop | 正式版中期 |
| Lua 等受限脚本 Mod | 核心玩法稳定后评估 |
| 任意 C# DLL 或系统级代码 Mod | 不提供官方支持 |

首版不开发 Mod 浏览器、加载器、依赖管理、创意工坊和脚本运行环境。首版只保证未来加入这些能力时，不必重做全部内容 ID、存档和文本系统。

### A20.2 稳定 ID 规范

所有内容 ID 使用：

```text
命名空间.类型.名称
```

核心内容示例：

```text
core.resource.iron
core.resource.alloy
core.building.machine_gun_tower
core.enemy.devourer
core.tech.basic_metallurgy
core.fate.pocket_universe
core.event.leader_rescue
```

未来 Mod 内容示例：

```text
baiyan.expansion1.building.railgun_tower
author.mod.mod_name.enemy.custom_beast
```

规则：

- 仅允许小写英文字母、数字和下划线；
- 至少由三段组成；
- ID 发布后不因改名、翻译或美术调整而改变；
- ID 废弃时通过迁移映射指向新 ID，不能直接复用给其他内容；
- 重复 ID、未知引用和循环依赖必须在启动校验阶段报告；
- 核心命名空间 `core` 只允许官方内容使用。

### A20.3 内容注册表

所有内容通过唯一 `ContentCatalog` 注册，而不是由系统分别扫描文件夹。

每条注册记录至少包含：

```text
StableId
ContentType
ContentSource
SchemaVersion
Definition
AssetAddress
LocalizationPrefix
```

首版 `ContentSource` 固定为：

```text
SourceId: core.content.demo
Version: 1.0.0
```

未来 Mod 使用自己的来源和版本。加载顺序为核心内容→官方扩展→用户 Mod；默认禁止静默覆盖相同 ID。需要覆盖时，Mod 必须在清单中明确声明目标和兼容版本。

### A20.4 本地化 Key

所有显示文本使用 Key：

```text
ui.action.build
ui.status.production_blocked
building.machine_gun_tower.name
building.machine_gun_tower.description
event.leader_rescue.choice_now
event.leader_rescue.choice_delay
```

首版只提供简体中文表，但数据结构支持多个语言表。缺失 Key 时：

1. 开发构建显示 `[missing:key]`；
2. 发布构建回退到简体中文；
3. 同时写入错误日志；
4. 不允许直接显示空字符串。

### A20.5 Mod 分阶段路线

**阶段 D1：内部内容扩展**

- ScriptableObject 配置；
- 命名空间 ID；
- 内容注册和校验；
- 本地化 Key；
- 版本化存档；
- 不扫描外部 Mods 目录。

**正式版早期：数据 Mod**

```text
Mods/
└─ ExampleMod/
   ├─ manifest.json
   ├─ resources.json
   ├─ buildings.json
   ├─ enemies.json
   ├─ tech.json
   └─ localization/
```

`manifest.json` 至少包含：

```json
{
  "id": "author.mod.mod_name",
  "name": "Example Mod",
  "version": "1.0.0",
  "gameVersion": ">=0.4.0 <0.5.0",
  "dependencies": [],
  "loadAfter": [],
  "contentSchema": 1
}
```

**正式版中期：资产与分发**

- Addressables 或受控 AssetBundle；
- Mod 管理界面；
- 启用、禁用、排序和错误报告；
- Steam Workshop；
- 存档记录启用的 Mod 和版本；
- 安全模式启动。

**脚本 Mod**

只有当数据 Mod 无法满足主要创作需求时再评估。优先采用受限制事件 API 和沙箱脚本，不加载任意外部 C# DLL。

### A20.6 Mod 存档行为

- 存档记录游戏版本、存档结构版本、内容源和版本列表；
- 未知建筑加载为“缺失内容占位体”，保留位置、占格和原始 ID，但停止生产；
- 未知资源保存在孤立资源表中，重新启用 Mod 后恢复；
- 未知科技和事件状态保留原始 ID，不自动视为完成；
- 禁用 Mod 前提示该存档依赖的内容；
- 安全模式允许忽略外部内容并生成新的恢复存档，不覆盖原存档。

## A21. 更新兼容与开发治理

### A21.1 版本策略

使用语义化版本：

```text
主版本.次版本.修订版本
```

- 修订版本：Bug 和数值修正，不破坏存档；
- 次版本：增加兼容内容，允许存档迁移；
- 主版本：规则或数据结构大幅变化，可以声明不兼容，但必须保留旧版分支或导出方案。

每个存档包含：

```text
gameVersion
saveSchemaVersion
contentSources
createdAt
updatedAt
```

### A21.2 存档迁移

- 每次结构变化新增单向迁移函数，例如 `V1→V2`；
- 不直接修改旧迁移逻辑；
- 迁移前自动备份；
- 迁移失败保留原文件并显示可理解错误；
- 官方 ID 改名必须维护旧→新映射；
- 至少保留当前和上一正式版本的存档回归样本。

### A21.3 AI 架构治理

项目只允许存在一套：

- 内容注册表；
- 库存；
-事件总线；
- 游戏时钟；
- 存档入口；
- 本地化入口；
- 输入动作表。

AI 任务开始前必须搜索现有接口，不得新建同义系统。新增跨系统抽象必须同时说明：

- 当前调用者；
- 玩家价值；
- 为什么已有接口不能满足；
- 测试；
- 存档影响；
- 删除或替代的旧接口。

关键架构决策记录在 `Assets/_Project/Docs/ArchitectureDecisions.md`，每条包含背景、选择、替代方案、后果和日期。

### A21.4 Windows 实机验收

虽然开发设备可以是 macOS，但每个候选发布版本必须在真实 Windows 设备验证：

- 中文字体和缺字；
- Windows 路径与存档权限；
- DPI、窗口、全屏和多分辨率；
- 键鼠焦点和输入法；
- 解压、首次启动和退出保存；
- 杀毒软件误报；
- 打包资源引用；
- 30-60 分钟性能和内存；
- 无开发者本机绝对路径泄漏。

没有 Windows 实机结果的构建不能标记为公开发布候选版。

## 一、世界背景

### 1.1 核心世界观：循环纪元

#### 1.1.1 前代：星海人类联邦

在入侵者降临之前，这个世界的统治者是 **星海人类联邦**（Starsea Human Federation）——一支纯粹的人类文明。他们在漫长的发展中走过了多条路线（科技、修仙、灵能、血肉），最终抵达了**九级巅峰**，开始向十级（神级文明）发起冲击。

"升维"——将整个文明从低维物理宇宙提升到更高维度的存在形态——需要**全路径统合**。科技、灵能、修仙、血肉：四条路线必须在同一个文明体内实现真正的融合，而非简单的混搭。星海联邦虽然在多路线上有卓越成就，但他们终究是以人类的框架去理解每一条路线——修仙被当作"灵气工程学"，血肉被当作"生物改造技术"，灵能被当作"意识科学"。他们**没有真正成为**每条路线的信徒，只是用人类的视角在模仿。

**升维失败**。十级的门槛反弹，世界法则大面积破碎——物理常数开始漂移、时间在某些区域静止、生物在另一些区域失控变异。这就是"怪物"的起源：它们是被破碎法则扭曲的本土生物，是这个世界的**免疫反应**。

联邦意识到失败不可逆。在缓慢崩解的过程中，他们用最后的力量做了两件事：

1. **"时流观测"**——联邦在九级巅峰时已经掌握了概率预测技术。不是自由的时间旅行（那是十级的领域），而是看到未来时间线的"概率簇"。他们看到了三条线：
   - 自己的毁灭（确定）
   - 入侵者的降临（确定）
   - 一个“白点”——在遥远概率分支中，有一支**本世界诞生的文明**，在一个来自更高维度的外部意识的帮助下，会在未来完成升维（模糊但存在）

2. **赌在白点上**——联邦没有选择与入侵者正面对抗（对抗不在那条通往白点的路径上），而是将全部残余力量注入**遗产系统**：编码到世界法则深处、融入本世界文明的血脉、设计为自适应隐形和阶梯式释放、隐藏到入侵者找不到的层面。

#### 1.1.2 入侵者："监察者"的寄生

升维失败引发的时空波动像一道信号，跨越星系团传到了 **"监察者"**——一个八级巅峰的寄生种族。它们降临这个破碎的世界、寄生、掠夺、开始研究。

监察者的核心目标：**找到并控制星海联邦留下的遗产**（九级巅峰产物，监察者离九级还差最后一步）。遗产绑定在世界本土文明的血脉中——毁灭了就永远找不到。所以监察者不毁灭世界，而是：

- 不断重启文明循环
- 暗中操控世界机制（关注度、标准线、天劫、怪物进化）
- 观察每一次循环中本土文明的发展路线
- 试图破解遗产的锁定机制
- 一旦当前循环的文明发展到可能发现真相，就收割重启

**但遗产是跨循环积累的**。每次循环中被毁灭的文明，其研究路线、失败教训、创新尝试都被遗产默默吸收。研究派从扫描数据中能看到遗产在增长——但他们陷入了囚徒困境（见 1.3.1）。N个循环之后，遗产已经积累了足够的认知，等待那个能承载它的文明——以及那个外部意识——出现。

当前循环中诞生的，就是玩家。

#### 1.1.3 三层世界结构

| 层级 | 构成 | 状态 |
|------|------|------|
| **底层** | 星海人类联邦的废墟 + 之前多个循环中被毁灭文明的叠加遗迹 | 被入侵者掩盖，但遗产跨循环积累中 |
| **中层** | 玩家文明 + 其他AI势力（当前循环的原生文明） | 在循环中挣扎发展，尚未意识到真相 |
| **上层** | "监察者"（八级巅峰入侵者） | 暗中操控循环、压制文明突破、三派内斗 |

---

### 1.2 星海人类联邦：崩解中的布局

#### 1.2.1 "时流观测"与白点预言

联邦在九级巅峰时掌握的**时流观测**技术（非时间旅行，而是概率簇可视化）揭示了三件事：

1. 十级的门槛——需要全路径的**真正统合**，不是人类的框架去"包容"其他路线，而是每条路线都被**平等地活出来**。联邦做不到——他们太"人类"了
2. 入侵者必然降临——升维失败引发的时空波动会像血在水中扩散一样被远处的掠食者嗅到
3. 一个"白点"——在所有概率分支的尽头，联邦看到了一件无法解释的事：N 个循环之后，**一个来自更高维度的意识**会与一支本土文明建立连接。这个外部变量不在因果链内——时流观测能看到它的"影响痕迹"但看不到它本身。它的出现会让原本必然失败的路径拐弯。联邦无法预测这个高维意识会做什么，只能确定**它出现后，升维概率从零变成了非零**

联邦没有选择对抗。对抗不在通往白点的路径上。他们把每一分残余力量都用来为那个白点铺路——遗产的一切设计，都是为了等到那个外部意识（即**玩家**）降临，为它准备好一套"操作系统"：不用理解，只需操作。

> **打破次元壁**：联邦时流观测预测到的"高维意识"就是屏幕前的玩家。你不是在扮演一个角色——你就是你，一个来自比游戏世界更高维度的真实存在。游戏中前期的叙事暗示这点（遗迹残响提到"不在因果链内的变量""外来的观察者"），后期直接揭示。

#### 1.2.2 遗产的工程设计

联邦的遗产不是一堆蓝图和武器的堆砌。它是一个**文明的种子**——设计为五层保护机制：

| 保护层 | 机制 | 效果 |
|--------|------|------|
| **血脉锁** | 遗产只对本世界出生的文明产生共振响应 | 监察者能看到遗迹的物理存在，但读不出遗产核心数据——它们不是"本地人" |
| **阶梯释放** | 遗产按承载文明的当前等级分层解锁 | 一级文明只看到一级的内容；遗产全貌到玩家接近九级时才完全展现——也防止玩家"噎死" |
| **自适应隐形** | 遗产嵌入世界物理法则底层 | 监察者的扫描工具无法将其与正常物理波动区分开 |
| **跨循环积累** | 每次被重启，遗产吸收该循环文明的创新与失败日志 | N个循环后，遗产数据库已经包含海量的"已证伪路径"和"最近似成功路径" |
| **外部激活锁** | 遗产的"翻译层"需要外部高维指令才能启动 | 前 N-1 个循环，遗产的操作系统越来越完善，但键盘前没人坐。本土文明只能用遗产的"基础功能"（部分科技加成、遗迹感应），永远无法让它全功率运转。直到这一轮——玩家坐下、点击"建造"——遗产才第一次完整响应。监察者研究了几十个循环都没搞明白的遗产全貌，不是因为锁难破解，而是**锁的钥匙不在因果链内** |

> **灵感来源**：阿西莫夫《基地》的"谢顿计划"（文明级数学预测 + 关键节点引导）；《我的模拟长生路》"还真"系统（轮回锚点 + 跨循环信息积累）+ "法不可同修"（每条路线需要真正的专属承载者）

#### 1.2.3 崩解中的遗民：五种存续形态

联邦不同路线、不同地区的人类选择了不同的方式渡过崩解：

| 存续形态 | 描述 | 游戏内互动 |
|----------|------|-----------|
| **数据残响** | 部分人将意识上传至遗产系统，化为AI引导程序。已不是"活着"，但能在关键文明节点主动与玩家沟通（类似《基地》里谢顿的全息录像——"谢顿危机"机制） | 中期解锁遗迹深处的通讯终端后可对话 |
| **深眠者** | 科技路线冷冻休眠者，藏于最深层遗迹中，等待"白点"出现时唤醒。醒来时发现世界已面目全非、自己的文明已成为传说 | 后期可唤醒为特殊顾问/角色加入文明 |
| **融入法则者** | 修仙路线放弃肉身，神识融入物理法则。已无法对话，但表现为世界机制中的"偶然善意"——一次莫名避开的天劫、一个"恰好"出现的逃逸窗口 | 贯穿全程的隐性存在；后期揭示其来源 |
| **变异后裔** | 血肉路线幸存者，肉体崩解中变异，已无人形。在偏远星区的暗处形成独立种族，有自己的文化和语言 | 可作为隐藏势力接触；他们可能视玩家为"背叛肉身的后代"，极度敌视纯粹机械路线 |
| **残响记录** | 预设的加密信息，在文明达到特定里程碑时自动触发。一段全息录像、一段加密文本、一组坐标 | 叙事片段形式推进——但玩家不知道这些残响的线索是否还在当前循环中有效（世界已被篡改） |

#### 1.2.4 留白：联邦刻意未留的东西

联邦在遗产中有意**未留下**某些知识：

- **完整的升维蓝图**——如果直接给后人画好路径，后人会走在联邦设下的框架里。而联邦自己正是因为"框架"太人类化才失败的。升维的最后一步——十级的门槛——必须由后人用自己的方式跨过去
- **监察者的弱点**——联邦知道，如果在遗产中写明"怎么杀监察者"，遗产一旦被监察者破解就会被反利用。他们选择了信任后人：一个能从循环中活到揭露真相的文明，自己一定有能力找到监察者的致命缺陷
- **一段关于"白点"中被看到的那支文明是谁的确认信息**——玩家全程不知道白点中那个人"究竟是不是自己"，只能靠行动去证明。这也是联邦留下的最后考验

### 1.3 外来入侵者（"监察者"）

监察者自称 **"监察者"**。在它们的文明体系里，这个被锁死的循环世界是一个**研究标本**——编号、归档、按周期观察。

#### 1.3.1 基本参数

- **文明等级**：八级巅峰，差一步到九级（空间折叠、预见危险、自由星系团间航行）
- **形态**：有实体的种族；大后期通过剧情揭露真实形态与舰队集群
- **已融入世界机制**：关注度、标准线压制、天劫、怪物自适应进化——背后都是监察者铺设的调控网络
- **核心恐惧**：遗产是九级巅峰产物。监察者离九级还差一步——遗产一旦被完全激活，反噬的可不只是本世界内的监察者驻军，而是它们的**整个文明**
- **囚徒困境**：研究派**知道**遗产在跨循环积累。每次重启循环，遗产数据库就多一层——他们从扫描数据中能看到。但他们陷入了死局：停止循环 = 毁灭世界 = 遗产随世界一起消失 = 永远拿不到九级巅峰的秘密。继续循环 = 遗产继续积累 = 终有一天积累满。这不是一个蠢不蠢的问题，而是一场赛跑——**在遗产积累满之前破解它**。他们选了继续跑，赌自己跑得过。起跑线站在遗产那边

#### 1.3.2 内部三大派系

##### 研究派（主流 / 占多数席位）

- **主张**：维持循环、继续观察。遗产是危险，更是千载难逢的**研究样本**。彻底破解遗产机制之前不能毁灭世界
- **行为**：系统性压制文明（标准线、天劫、怪潮）；对玩家做"极限测试"；偶尔**反向保护玩家**——如果毁灭派要提前灭世破坏数据
- **玩家感知**：感受到的"世界机制"大多来自研究派

##### 毁灭派（少数激进派）

- **主张**：遗产太危险，必须立刻终结。八级文明研究九级巅峰遗产 = 蚂蚁解剖大象。宁可不拿
- **行为**：绕过研究派独走，用超规格手段（陨石、轨道轰炸、局部法则崩溃）。内部的独走给了玩家可乘之机
- **玩家感知**：某些"自然灾害"回头想才意识到有组织在动手

##### 田园派（少数叛变/被同化者）

- **来源**：之前N个循环中，部分监察者只是在**观察和动摇**——目睹文明反复被收割，私下与本世界的数据残响/融入法则者产生微弱交流，但从未出手。它们不敢。但每一次循环都积累一层疑虑。到了这一轮，积累突破了临界点——它们第一次实际行动。这也解释了为何玩家这一轮线索集中涌现：不是每轮都有，就这一轮
- **行为**：暗中留下线索（遗迹中的不明来源信息）、干预机制（微调关注度、抹掉超标记录）、在关键时刻制造"信息雾"帮玩家逃避锁定
- **接触梯度**：
  - 早期：遗迹中的来源不明文字、反常的机制波动
  - 中期：特定遗迹 → 单向加密通讯
  - 后期：直接接触（形态已本土化改变），可结盟——代价是文明可能被同化物质污染，科技路线产生不可预知变异

#### 1.3.3 三派博弈时刻表

| 时刻 | 动态 | 玩家窗口 |
|------|------|---------|
| 接近文明标准线 | 研究派加压 vs 毁灭派抹除 vs 田园派拖延 | 三派僵持 → 额外备战时间 |
| 毁灭派独走 | 研究派封锁，田园派泄露信息 | 从打击中提取"非自然"证据 |
| 发现关键遗迹 | 研究派提高监控，毁灭派准备破罐破摔 | 田园派引导绕开监控 |
| 遗产部分激活 | 研究派恐慌、毁灭派暴怒、田园派看到希望 | 三派内讧 → 监察者效率下降 |
| 大后期真相揭露 | 三派全面分裂 → 监察者内战 | 与田园派结盟，利用内战反击 |

#### 1.3.4 前期入侵者线索

- "自然灾害"有精准规律
- 关注度数值莫名剧烈波动
- AI势力突然改变行为模式（友好伙伴一夜宣战）
- 遗迹入口被异常力量刻意封堵
- 某些研究在接近特定层级时频繁"偶然失败"

#### 1.3.5 压制梯度

- 越远离监控核心，压制越小
- 偏远星球监控密度远低于中心星域
- 关键性突破（文明升阶、遗产激活）时距离无差别——全舰队级响应

## 二、游戏核心机制

### 2.1 命轨（星海联邦的遗产）🌟

#### 2.1.1 本质

**命轨**是星海人类联邦为「白点」（玩家）准备的**规则级能力种子**。它是九级巅峰文明的遗产——差一步就是神级（创造空间、重写物理法则、发现平行宇宙）。

命轨不是数值增益。每一条命轨**改写一条世界规则**——和以撒的结合中 Brimstone 把眼泪变成激光、Mom's Knife 替换攻击方式一样，命轨让你在某些维度上**和所有人玩的不是同一套规则**。

- **开局命轨**：三选一。每局从 24 条命轨池中随机抽取三条。你选择的不是 build，是**你的文明如何作弊**
- **升级命轨**：每条命轨 1-9 级，共 8 次升级。核心数值 = 基础值 × 2^等级。升级方式待定

### 2.2 文明等级系统

玩家**主动选择**升阶。升阶条件通过剧情/事件提示，不公开透明。越高阶越困难，入侵者压制越强。

| 等级 | 名称 | 描述 |
|------|------|------|
| **一级** | 行星文明 | 完全吸收并控制母星能量资源，管理行星表面环境 |
| **二级** | 恒星文明 | 控制并利用恒星能量，对整个星系进行操控 |
| **三级** | 星系文明 | 银河系内自由穿梭，多元能源（暗物质、黑洞等） |
| **四级** | 超星系文明 | 超越星系限制；"降维概念"在此阶段形成 |
| **五级** | 时间文明 | 突破时间限制，自由访问时间轴任意节点 |
| **六至八级** | — | 空间穿越、星系团间航行、操控生物能量、预知规避危险 |
| **九级** | 时空边缘文明 | 超星系团航行、空间折叠技术（飞船小如芥子内有乾坤） |
| **十级** | 神级文明 | 创造空间、发现平行空间、创造新宇宙 |

> 监察者为**八级巅峰接近九级**。玩家从一级开始，开局命轨提供九级巅峰能力种子——理论上监察者压不住你，但种子需要时间成长。

#### 2.2.1 叙事揭示节奏

真相不是到了九级忽然砸下来，而是随着文明升阶层层剥开：

| 等级 | 叙事揭示 | 玩家感知 |
|------|----------|----------|
| **1-2 级** | 世界"不对劲"——自然灾害有规律、关注度莫名波动、遗迹中的记录互相矛盾 | 直觉：我不是第一个住在这里的人 |
| **3-4 级** | 循环存在的证据浮现——不同文明的遗迹叠在同一地层，时间跨度远超正常文明寿命 | 确信：世界在反复重启。有人在操控 |
| **5-6 级** | 确认外部操控者（监察者）的存在 + 发现三派系的痕迹 | 发现敌人有名字、有组织、有分歧 |
| **7-8 级** | 理解遗产本质——为什么你能用多路线 + 联邦白点预言 + 监察者内部分裂 | 明白自己不是侥幸，是被等到的 |
| **9 级** | 一切汇合：遗产全貌解锁 + 田园派正式结盟 + 正面对抗监察者 | 从「被研究」到「主动打」 |

### 2.3 文明发展方向

#### 2.3.1 核心路线

| 路线 | 特征 | 军队形态 | 示例能力 |
|------|------|----------|----------|
| **纯粹科技** | 机械、能量武器、自动化 | 机甲军团、无人机蜂群 | 激光塔、等离子护盾 |
| **灵能** | 精神力量、意识操控 | 灵能战士、心灵操控者 | 精神力场、心灵链接 |
| **血肉飞升** | 生物改造、基因进化 | 变异兽群、生化士兵 | 酸液喷射、再生护甲 |
| **修仙** | 灵气修炼、法宝炼制 | 傀儡道兵、剑修 | 飞剑阵列、符箓阵法 |

#### 2.3.2 路线机制

- **无惩罚混搭**：解锁 ≠ 必须使用。大多数路线自由混搭
- **跨侧融合**：专属科技需要多种路线的前置（机械+修仙 → 灵能机甲）
- **隐藏科技提示**：拥有多侧前置后出现融合提示
- **跨侧促进**：不同侧的前置加速高等科技研究
- **互斥路线**：极少数极端路线互斥
- **参考《我的模拟长生路》"法不可同修"的逆向设计**：玩家的"遗产"恰恰打破了"一条路走到底"的束缚——联邦正是被单一框架限制才失败的

### 2.4 时代演进系统

玩家解锁关键超前科技或升阶时触发**全局统一**的时代演进。

#### 2.4.1 时代类型

玩家行为积累对应**轨道值**（见 4.4），配合科技进度触发时代演进：

| 走向 | 触发条件 | 世界变化 | 掉落物 |
|------|----------|----------|--------|
| **机械飞升** | 异化度 ≥ 40 + 科技路线已研究 ≥ 6 节点 | 赛博废土，怪物机械化 | 芯片、超导材料 |
| **深渊变异** | 变异度 ≥ 40 + 血肉路线已研究 ≥ 6 节点 | 孢子覆盖，巨型变异体 | 生物质 |
| **维度降临** | 灵震度 ≥ 40 +（修仙或灵能路线）已研究 ≥ 6 节点 | 重力异常，时空裂缝 | 虚空物质 |

> 触发时代后，对应轨道 **+10**——时代本身会加速危机进程。

#### 2.4.2 抵抗 vs 适应

每座城市可独立选择：

| 选择 | 代价 | 收益 |
|------|------|------|
| **抵抗时代** | 额外针对性攻击 | 该侧完整研究路径 + 进度 + 材料 + 独特剧情奖励 |
| **适应时代** | 无额外奖励 | 该时代科技研究大幅加速 |

> 复合科技路线可**提前触发**时代。未控制的城市自动**被动适应**（解锁少量基础科技作为生存底线）。

### 2.5 移动城市与多城系统

#### 2.5.1 移动 vs 展开

| 状态 | 优势 | 限制 |
|------|------|------|
| **移动态** | 自由探索、随时撤离 | 规模上限、长周期研究不可进行 |
| **展开态（堡垒）** | 防御加成、生产加成、大规模研究 | 初始读条（科技缩短 → 最终秒开） |

> 也可永久扎根为固定基地。选择权在玩家。

#### 2.5.2 多城市管理

- **同时运转**：所有城市自主运作（参考文明6）
- **控制切换**：一次只控一城；切换需领袖亲自前往
- **城主委派**：任命角色/继承人管理
- **自动防御 + 通知**：未控制城市受攻击自动防御，系统通知
- **远程指挥**：科技解锁
- **领土 + 迷雾**：领土内可见，外需侦察/科技

#### 2.5.3 城市定位与基础设施

- **定位自由**：工业城、军事要塞、修仙圣地、贸易枢纽...由玩家决定
- **面积**：无上限，超过文明标准线吸引大量袭击
- **仓库**：可多建，科技线扩容
- **资源传输**：城市间交通线；运输方式随科技升级（道路→铁路→管道→无人机→传送门）
- **运输安全**：可沿途造塔形成走廊 / 派护卫队 / 绕路 / 后期科技替代
- **自给 vs 分工**：完全由玩家决定

### 2.6 领袖 / 英雄系统

#### 2.6.1 角色定位

玩家是一个**具体角色**——文明领袖、高战力单体（不是站着放 buff 的指挥官，而是战场最强单位）。

- 可亲自下场（割草/打Boss）
- 可在任意城市间调动（切换需旅行前往）
- 专精方向取决于个人技能树和天赋

#### 2.6.2 成长体系

| 维度 | 机制 |
|------|------|
| **个人经验** | 战斗独立成长，不依附城市 |
| **外部装备** | 需城市工厂/炼器/研究系统制作 |
| **个人技能树** | 专属天赋树——决定战斗风格 + 管理加成 |
| **天赋** | 每个角色随机生成，不可更改 |

#### 2.6.3 角色类型与城市联动

| 类型 | 在场效果 |
|------|----------|
| **战士型** | 附近炮塔攻速加成（"士气"） |
| **科研型** | 坐镇城市研究速度翻倍；本人脆皮 |
| **修仙型** | 远程为塔附魔；需打坐回复灵力 |
| **经商型** | 贸易收入增加、外交成本降低 |

#### 2.6.4 死亡与继承

- 死亡 → 国家**短暂发展停滞** + 可能叛乱（如果忠诚不够）
- 换新领袖：**从零培养**
- **开局无领袖**（初始100人自由状态）：
  - 废土中招募随机角色
  - 人口满1000 → 选举产生首位领袖

### 2.7 继承人与内部政治

#### 2.7.1 继承人

- **独立角色**：自己的天赋、技能树、专精方向
- **上岗前作用**：管理第二城、带队远征
- **培养意义**：避免领袖死后文明从零开始

#### 2.7.2 叛变与反利用

- 可能叛变（独立意志 + 权力斗争）
- 会带走管理的城市（如果该城忠诚度不够）
- **预警**：忠诚下降、私下囤资源、拒绝命令
- **应对**：镇压 / 安抚 / 先下手
- **反向**：可策反敌人势力的将领/继承人

#### 2.9.4 伤害类型与护甲克制

**五种伤害类型**：

| 伤害类型 | 主要来源 | 特点 |
|----------|----------|------|
| **物理** | 子弹、炮弹、近战斩击 | 稳定无短板，通用基础伤害 |
| **能量** | 激光、等离子、火焰 | 烧重甲，怕生物壳 |
| **灵能** | 精神灼烧、心灵震爆 | 贯穿灵力罩，被同类型灵能盾抵抗 |
| **生物** | 酸液、孢子、寄生 | 融重甲，同类型互克 |
| **真元** | 飞剑、符法、灵力 | 净化生物壳，同类型互克 |

**五种护甲类型**：

| 护甲 | 常见于 | 特征 |
|------|--------|------|
| **轻甲** | 普通杂兵 | 无短板，100% 承受所有伤害 |
| **重甲** | 重装怪、机械体 | 物抗高，能被能量和生物克制 |
| **灵能盾** | 灵能怪、监察者探针 | 灵能低效，物理可穿透 |
| **生物壳** | 变异体、血肉怪 | 能量低效，真元和灵能克制 |
| **灵力罩** | 修仙怪、古遗迹守卫 | 真元低效，灵能可贯穿 |

**克制矩阵（130/100/70 三值体系）**：

| ↓伤害 \ 护甲→ | 轻甲 | 重甲 | 灵能盾 | 生物壳 | 灵力罩 |
|---------------|------|------|--------|--------|--------|
| **物理** | 100 | 70 | 130 | 100 | 100 |
| **能量** | 100 | 130 | 100 | 70 | 130 |
| **灵能** | 100 | 100 | 70 | 130 | 130 |
| **真元** | 100 | 100 | 100 | 130 | 70 |
| **生物** | 100 | 130 | 130 | 70 | 100 |

> 物理/真元平均 100%（稳定基础），能量/灵能/生物平均 106%（峰值高但被克制时掉到 70）。克制幅度 130/70 = 1.86×，不极端但足够影响战术。

#### 2.9.5 Buff / Debuff 体系

**通用 Buff**（所有路线共享）：

| Buff | 效果 | 来源 |
|------|------|------|
| 攻击增幅 | 伤害 +N% | 研究站、奇点 |
| 防御加固 | 建筑耐久 +N% | 城墙升级、奇点 |
| 移速提升 | 城市/军队速度 +N% | 道路、奇点 |
| 生产效率 | 采矿/冶炼/研究速度 +N% | 领袖坐镇、奇点 |
| 射程扩展 | 塔/远程单位范围 +N% | 奇点、建筑升级 |
| 再生 | 建筑/军队缓慢自回血 | 血肉增益、奇点 |

**路线专属机制**：

| 路线 | 机制 | 描述 |
|------|------|------|
| **科技** | **过载** | 激活后 5s 内攻速翻倍 + 能量伤害 +30%，结束后过热停火 3s。CD 30s |
| **修仙** | **剑意** | 飞剑命中叠层（上限 20），满层时触发斩杀：层数×5% 最大生命值的真实伤害。斩杀后清零 |
| **血肉** | **感染** | 生物伤害附加感染（持续 2%/s），满 10 层爆发 → 周围 3 格全部获得 5 层 |
| **灵能** | **共鸣** | 灵能命中标记目标（5s），任意被标目标受灵能伤害时全标目标同步承担 30%。上限 10 目标 |

**Buff 来源层级**：

```
奇点选择 ──→ 永久被动 (全局生效)
科技研究 ──→ 可切换 (解锁后手动激活)
领袖技能 ──→ 区域Buff (领袖在场)
丹药/消耗品 ──→ 临时 (有持续时间)
命轨 ──→ 规则破格 (如"过载无过热")
```

**Debuff（敌方可施加）**：瘫痪（建筑停摆）、腐蚀（持续掉血）、冻结（移速骤降）、灵力压制（修仙/灵能减弱）、信号干扰（物流区减半）

### 2.11 开局流程

1. **开局状态**：一座上一循环文明留下的移动城市残骸 + 100个无意中激活了它的幸存者 + 无领袖。城市不是玩家建造的——它是一堆勉强运转的废墟。这 100 人不是管理者，只是栖居其中的流浪者。研究、建造、领袖——这些都是激活城市之后才逐渐学会的
2. **命轨选取**：激活城市的瞬间，遗产响应——弹出命轨三选一。这是遗产第一次等到外部指令，它给出了三条最可能通路
3. **背景**：默认随机（落难军阀遗孤 / 流放科学家 / 流浪修士 /...），也可主动选择
4. **起始位置**：默认随机，可选（安全荒原 vs 资源丰富多怪的辐射区）
5. **领袖获取**：招募 或 人口满1000选举

### 2.12 胜利与失败

| 条件 | 结果 |
|------|------|
| 所有城市被摧毁 | **失败** |
| 世界被毁灭 | **失败** |
| 带领文明离开这个世界 | **伪胜利（坏结局）** ⚠️ |
| 解决世界危机 | **胜利** |
| 完成星海联邦未竟的升维 | **真胜利** |

> ⚠️ **关于「离开世界」**：遗产的血脉锁决定了一件事——遗产绑定的是这个世界，不是这个文明。如果玩家选择逃离、穿越传送门去另一个宇宙，遗产不会跟随。这意味着玩家抛弃了遗产、抛弃了联邦的赌注、也抛弃了「白点」的使命。监察者不会追击——因为他们要的是遗产，不是你这支逃走的文明。世界会在玩家离开后被重启，等待下一个循环、下一个文明、下一个外部意识的降临。**这不是胜利，这是放弃。** 但从玩家的视角，在逃离的那一刻他们不会知道——屏幕只会显示「你的文明存活了下来」，只有通关后回头看，才会发现这其实是循环中的又一次失败

### 2.13 资源与经济系统

#### 2.13.1 MVP 五种基础资源

| 资源 | 产出方式 | 各路线用途 |
|------|----------|-----------|
| **铁矿** | 采矿站 | 科技→合金 / 修仙→灵铁 / 血肉→骨钢 / 灵能→共振金属 |
| **能晶矿** | 采矿站 | 科技→电力 / 修仙→灵石提炼 / 血肉→代谢燃料 / 灵能→精神力增幅 |
| **石材** | 采石场 | 全路线通用基础建材（城墙、地基、防御工事） |
| **生物质** | 怪物尸体回收 / 种植 | 科技→碳纤维 / 修仙→灵草肥料 / 血肉→核心原料 / 灵能→意识载体 |
| **水源** | 采集站 / 净化 | 人口维持 + 工业冷却 / 炼丹 / 培养 |

#### 2.13.2 混合资源体系三层结构

```
第一层：通用原材料（所有路线共享）
    铁、能晶、石材、生物质、水源
    ↓ (分叉：路线专属加工)
第二层：路线中间品
    铁矿 → 科技高炉 → 合金
    铁矿 → 修仙灵火 → 灵铁锭
    铁矿 → 血肉菌落 → 活性金属骨骼
    铁矿 → 灵能共振炉 → 共振金属
    ↓ (再加工)
第三层：路线终产物
    合金 → 机甲 / 灵铁 → 飞剑 / 活性金属 → 巨兽装甲
```

#### 2.13.3 路线原生资源（仅该路线可采集）

| 路线 | 专属资源 | 出现环境 |
|------|----------|----------|
| 科技 | 稀土、铀矿 | 辐射区、小行星带 |
| 修仙 | 灵石、灵脉 | 灵气浓郁区、古战场 |
| 血肉 | 活性生物质、变异基因 | 变异巢穴、巨兽尸骸 |
| 灵能 | 精神力结晶、意识碎片 | 精神污染区、上古遗迹 |

#### 2.13.4 跨路线转化

不同路线材料可互相转化，需研究对应转化科技。转化有效率损耗，科技等级越高损耗越低。

#### 2.13.5 扩展接口

每种基础资源预留扩展 slot：品质层级（普通→史诗）、路线专属衍生、特殊变体（如星陨铁——仅陨石事件产出）。新增资源只需在此框架加一行。

### 3.3 数值框架（阶梯式增长）

#### 3.3.1 怪物与防御塔 DPS 阶梯

文明升阶是难度跃迁点，阶内平缓增长：

| 阶段 | 基础塔 DPS | 同级怪血量 | 单塔击杀时间 |
|------|-----------|-------------|-------------|
| 未升阶（一级前） | ~20 | ~60 | 3 秒 |
| 一级文明（T2 塔） | ~60 | ~200 | 3.3 秒 |
| 二级文明（T3 塔） | ~150 | ~500 | 3.3 秒 |

> 核心原则：单塔击杀同品质普通杂兵 ≈ 3 秒。玩家通过数量/升级/Buff 追求更高效率。

#### 3.3.2 资源产出与消耗

> **历史草案提示**：下表不用于首版 Demo。按照本表原数值，一座持续开火的机枪塔实际需要约 12 座采矿站，而非 1 座。首版统一执行 A6.2 的“2 采矿站→2 冶炼厂→1 装配厂→1 机枪塔”基线。

| 建筑 | 产出 | 消耗 |
|------|------|------|
| 采矿站（1 级） | 1 铁矿 / 10s | — |
| 冶炼厂 | 1 合金 / 30s | 3 铁矿 |
| 装配厂 | 1 弹药 / 20s | 2 合金 |
| 机枪塔 | — | 1 弹药 / 5s（持续开火） |

> 1 采矿站 ≈ 支撑 1 座持续开火机枪塔。玩家需不断补产能，驱动自动化流水线扩张。

#### 3.3.3 文明升阶条件（多维度加权，达任一即可）

| 维度 | 一级要求 | 二级要求 |
|------|----------|----------|
| 人口 | ≥ 1000 | ≥ 5000 |
| 已研究科技 | ≥ 5 | ≥ 15 |
| 城市数 | ≥ 1 | ≥ 3 |
| 防御规模 | 塔 ≥ 2 | 塔总数 ≥ 10 |
| 单一突破 | 任意路线 T2 | 任意路线 T3 + 1 跨路线桥 |

#### 3.3.4 关注度阈值

| 关注度 | 阶段 | 效果 |
|--------|------|------|
| 0-29 | 安全区 | 日常游荡，无组织打击 |
| 30-59 | 关注区 | 第一次定向打击，稀有怪概率 ×2 |
| 60-99 | 警戒区 | 大规模攻击，精英怪出现 |
| 100-149 | 危险区 | 多城同时被攻，史诗怪出现 |
| 150+ | 天劫区 | 天劫触发，监察者直接介入 |

> 每次升阶 +25 关注度。抵抗时代 +15。部分奇点可增减关注度获取速度。

## 四、世界危机设计

### 4.1 危机全貌

```
表面危机（开局即感知）
    ↓
真实危机（中期通过遗迹/线索逐渐发现）
    ↓
衍生危机（中后期基于玩家选择浮现）
```

### 4.2 表面危机

怪物潮、天劫、资源枯竭、文明标准线压制——监察者调控网络制造的日常威胁。

### 4.3 真实危机

循环纪元——发展过高的文明会被收割。一切灾难背后有规律跟推手。星海联邦的崩解、监察者的寄生、循环的本质——需要在遗迹和线索中拼接。

### 4.4 衍生危机轨道

玩家的路线选择不仅带来收益，也积累**不可逆**的轨道值。每条轨道只升不降（棘轮），与关注度的可逆性形成短期/长期两条压力线：

| 轨道 | 对应行为 | 40 预警信号 | 60 小危机（可逆） | 80 大危机（不可逆） |
|------|---------|------------|------------------|-------------------|
| **异化度** | 攀机械科技 | 工厂偶尔产出「异常零件」 | 流水线短暂停摆，修复后可降回 50 | 矩阵意志觉醒，部分机甲反叛 |
| **灵震度** | 修仙/灵能过深 | 天空极光、灵气读数异常 | 法术有概率失效，调低输出可降回 50 | 灵力波动引高维净化 |
| **变异度** | 血肉飞升极端 | 菌落池脉动、单位外观异常 | 培育单位有概率失控，暂停可降回 50 | 身体被植入「失控武器」标记 |
| **暴露度** | 多城/多星球扩张 | 侦察机在领土边缘频繁出现 | 一座前哨站被精准打击 | 监察者投放「镜像文明」 |

**轨道机制**：
- 每条轨道 0-100，**只升不降**（棘轮法则）
- 40：叙事预警，不产生实际惩罚
- 60：小危机触发，玩家可采取行动降回 50（暂停研究/停止扩张/调低输出）
- 80：大危机触发，不可逆，永久改变游戏局面
- 轨道值来源：每研究一个对应路线科技 +3~5、每建造一个对应路线建筑 +2、触发对应时代 +10

#### 4.4.1 非轨道衍生危机

以下危机不由数值轨道驱动，由玩家具体行为触发：

| 触发行为 | 引发的危机 |
|----------|------------|
| 掠夺前代遗迹 | 前代遗民仇恨积累 → 有组织反攻 |
| 保护/收容遗民 | 隐藏路线：联合前代破解收割；代价是科技树被污染 |
| 龟缩不作为 | 循环收割来得更早更猛烈 |

### 4.5 胜利路径

- 收集资源建造**跨世界传送门/方舟**，带领文明离开
- 利用九级巅峰遗产（命轨 + 奇点积累） + 联合前代遗民 → 正面对抗监察者
- 完成星海联邦未竟的**升维**——带着世界跳出当前物理宇宙
- 联合其他被监察者压制的平行世界文明 → 多世界联手
- 与田园派合作，从内部瓦解监察者
- 其他涌现式路径

## 七、设计原则

1. **玩家自由决定一切**：移动或定居、科技或修仙、扩张或坚守、抵抗或适应
2. **克制是个人开发者最重要的美德**：美术做减法，精力在打击感、数值、叙事
3. **数据驱动**：不把数值写死在代码里
4. **核心循环**："获得 → 被觊觎 → 备战 → 碾压 → 世界升级"
5. **持久世界**：不做局内局外分离
6. **开局外挂**：九级巅峰遗产（命轨 + 奇点） = 不对称优势
7. **三层叙事**：表面危机 → 怀疑异常 → 揭露监察者真相
8. **跨循环视角**：玩家不是第一个挑战者——站在N代前人的尸体上，而这些前人的遗产正在遗产系统中与你对话
